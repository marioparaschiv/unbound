# Benchmarks

Run `bun run bench <ref-or-worktree> <ref-or-worktree> [...]`, never a hand-rolled script. The first variant is the baseline. It takes the vphone lock (it waits for a `claim.sh` claim), runs `scripts/doctor.sh`, builds each variant once as a release would ship it (cached by commit), snapshots the device, runs the launches interleaved, and restores the device on every exit, Ctrl-C included. `bun run bench --restore` recovers a device a killed run left in its bench state.

- **Options.** Defaults: `--rounds 3 --warm 2 --cold 1 --idle-ms 25000 --addons none` (about 15 minutes for an A/B). `--addons none` measures core alone; every launch must log `Loaded 0 plugins.`. `--addons all` installs and enables every first-party iOS plugin; use it only when the change affects plugins. `--variants file.json` (`{"variants": [{"name", "ref", "env"}], "rounds"?, ...}`) sets build env switches; `--build-only` builds offline.
- **Setup.** `.env` needs `TAILNET_URL` (the tailnet hub, `http://100.65.233.54:8790` here). To publish, set `UNBOUND_BENCH_OUT=/home/dev/share/unbound-bench` and `UNBOUND_BENCH_URL=https://share.marioparaschiv.com/unbound-bench`.
- **Measures.** Startup in ms after Discord's runtime was created: Unbound's bundle executed, Unbound initialized, and Discord's first render, FCP and latest messages. Memory: Hermes heap, live allocations, GCs, process footprint and RSS, after init and at +25 s, plus Metro modules initialized at +25 s.
- **Reading the report.** `report.md` opens with a verdict per variant (exact Mann-Whitney U against the baseline), then one table per launch kind (n, median, range, IQR, Δ median, p) and a self-check proving each launch ran its variant's bundle sha, listing invalid launches and error lines. A gap inside the A/A noise floor is no difference. Below 4 launches per side no p can reach 0.05.
