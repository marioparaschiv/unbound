## :sparkle: What it does

- :text-a: Draws messages, names and body text in [Geist](https://fonts.google.com/specimen/Geist), every weight upright and italic.
- :text-size-change: Draws Discord's bold headings in [Poppins](https://fonts.google.com/specimen/Poppins).
- :code: Leaves code blocks in Discord's own font.
- :download: Tap **Apply** to download the fonts and save the pack under Design → Fonts → Presets. Relaunch Discord to see it everywhere.
