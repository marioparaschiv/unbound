## :sparkle: What it does

- :abc: Draws messages, names and body text in [Geist](https://fonts.google.com/specimen/Geist), every weight upright and italic.
- :large_blue_diamond: Draws Discord's bold headings in [Poppins](https://fonts.google.com/specimen/Poppins).
- :keyboard: Leaves code blocks in Discord's own font.
- :arrows_counterclockwise: Tap **Apply** to download the fonts and save the pack under Design → Fonts → Presets. Relaunch Discord to see it everywhere.
