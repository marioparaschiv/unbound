# Changelog

## [1.1.0] - 2026-11-12

### Added

- A toggle in the chat input turns Aussie Speech on and off, with Persist State and Auto Disable settings like Silent Message Toggle.
- About 150 more phrases, from "ta" and "arvo" to "no wukkas" and "Buckley's chance".

## [1.0.4] - 2026-11-11

### Changed

- Needs Unbound 3.0.0 or newer. The plugin was reorganised for it and works the same as before.

## [1.0.3] - 2026-11-03

### Changed

- Remove the opening line from the plugin's page on unbound.rip. The plugin works the same as before.

## [1.0.2] - 2026-11-03

### Changed

- Rewrite the plugin's page on unbound.rip in a shorter style. The plugin works the same as before.

## [1.0.1] - 2026-11-01

### Changed

- Starts once Discord has drawn its first frame, so it no longer delays Discord opening.

## [1.0.0] - 2026-10-31

### Added

- Initial release in Unbound's first-party plugins, for iOS and Android.
