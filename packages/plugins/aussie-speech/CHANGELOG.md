# Changelog

## [1.2.4] - 2026-11-17

### Changed

- Its chat input button moves into the Plugin Shortcut Panel while that plugin is on.

## [1.2.3] - 2026-11-17

### Fixed

- Its chat input button folds into the shared plugin button when the row is too narrow, so the send button stays on screen.

## [1.2.2] - 2026-11-14

### Fixed

- The chat input's plugin buttons fold behind one button once the draft spans lines or leaves no room, instead of jumping into a grid while you type.

## [1.2.1] - 2026-11-14

### Fixed

- The chat input toggle is the same grey as Discord's own buttons while off, instead of white.

## [1.2.0] - 2026-11-14

### Changed

- The toggle hides while the message box is empty unless it is on, and moves into a grid above the send button once a draft runs long.

## [1.1.0] - 2026-11-12

### Added

- A toggle in the chat input turns Aussie Speech on and off, with Persist State and Auto Disable settings like Silent Message Toggle.
- About 150 more phrases, from "ta" and "arvo" to "no wukkas" and "Buckley's chance".

## [1.0.4] - 2026-11-11

### Changed

- Needs Unbound 3.0.0 or newer. The plugin was reorganised for it and works the same as before.

## [1.0.3] - 2026-11-03

### Changed

- Remove the opening line from the plugin's page on unbound.rip. The plugin works the same as before.

## [1.0.2] - 2026-11-03

### Changed

- Rewrite the plugin's page on unbound.rip in a shorter style. The plugin works the same as before.

## [1.0.1] - 2026-11-01

### Changed

- Starts once Discord has drawn its first frame, so it no longer delays Discord opening.

## [1.0.0] - 2026-10-31

### Added

- Initial release in Unbound's first-party plugins, for iOS and Android.
