## :sparkle: What it does

- :shield-user: Shows each author's highest role next to their name in chat, as a pill with the role's colour.
- :gear: Optionally shows the highest role that has a colour instead.
- :text: Uses Discord's own role pill, so it fits beside names, server tags and bot tags; on narrow screens long names shorten to make room.
