## :sparkle: What it does

- :link: Select text in the message box and paste a link over it to get `[text](link)`.
- :text: Brackets in the selected text are escaped, and pasting a link over another link replaces it as usual.
- :code-fork: A port of MaskedLinkPaste for Vencord, by sunnie.
