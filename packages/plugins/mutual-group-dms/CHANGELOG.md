# Changelog

## [1.2.3] - 2026-11-26

### Fixed

- Text renders in Discord's font again. Discord renamed its text styles, so text using the old names fell back to the system font.

## [1.2.2] - 2026-11-24

### Fixed

- The store page shows the plugin's screenshots, which 1.2.1 published without. The plugin works the same as before.

## [1.2.1] - 2026-11-24

### Changed

- The store page shows screenshots of the plugin instead of a banner. The plugin works the same as before.

## [1.2.0] - 2026-11-24

### Changed

- Mutual group DMs open in a sheet with each group's icon and members, instead of a dialog.

## [1.1.0] - 2026-11-13

### Changed

- Mutual groups join Discord's mutual friends and servers line on profiles, in its style.

## [1.0.0] - 2026-11-13

### Added

- Initial release: the group DMs you share with someone on their profile, ported from Vencord's MutualGroupDMs by amia.
