# Changelog

## [1.2.1] - 2026-11-17

### Fixed

- Stickers picked into the message box send as links when you can't use them; before, only stickers sent on their own were caught.

## [1.2.0] - 2026-11-14

### Added

- Unlock stream quality: Nitro's stream resolutions and frame rates, and high quality video uploads, ported from Livie's StreamQuality.

## [1.1.1] - 2026-11-14

### Fixed

- Your own fake emojis and stickers now show as real ones too, instead of GIF links that open in the media viewer.
- Editing such a message links its unusable emojis again, so the edit keeps them.

## [1.1.0] - 2026-11-13

### Added

- Emoji links others sent with Fake Nitro show as real emojis, and messages that are only sticker links show as real stickers, without the link embeds.

## [1.0.0] - 2026-11-13

### Added

- Initial release, ported from Vencord's FakeNitro.
