Sticker Preview stops Discord from sending a sticker the moment you tap it in the sticker picker. The plugin holds the sticker and shows it above the chat input instead. Tap the preview to remove the sticker.

The send button stays on while a sticker waits. When you send, the plugin sends the sticker with the text you typed as one message, or the sticker alone if you typed nothing. If you pick more than one sticker, the preview shows the first one, and the message includes all of them. If the send fails, the plugin puts the stickers back.

Each channel keeps its own stickers. When you turn the plugin off, it removes every sticker that waits to be sent. The Preview Message plugin can show the stickers that Sticker Preview holds.
