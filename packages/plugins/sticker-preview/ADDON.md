## :sparkle: What it does

- :sticker: Tapping a sticker in the picker shows it above the chat input instead of sending it. Tap the preview to remove it.
- :paper-plane-2: Send posts the sticker with your text as one message, or the sticker alone. Pick several and the message includes all of them.
- :undo: If the send fails, the stickers go back.
- :msgs: Each channel keeps its own stickers. Turning the plugin off removes any that are waiting.
- :eye: The Preview Message plugin can show the stickers Sticker Preview holds.

## :gear: Settings

None. Pick a sticker and it waits for you.
