# Changelog

## [1.0.2] - 2026-11-24

### Fixed

- Channel names are cleaned in the channel list too, and stay clean when a channel is created or edited.

## [1.0.1] - 2026-11-14

### Fixed

- Discord no longer freezes while it sorts or searches many channels: each name is cleaned once, not on every read.

## [1.0.0] - 2026-11-14

### Added

- Initial release, after Equicord's CleanChannelName and the Dashless plugin for Vendetta: channel names show without dashes, emoji and decorative letters.
