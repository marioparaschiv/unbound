# Changelog

## [1.0.5] - 2026-11-26

### Fixed

- Text renders in Discord's font again. Discord renamed its text styles, so text using the old names fell back to the system font.

## [1.0.4] - 2026-11-24

### Fixed

- The store page shows the plugin's screenshots, which 1.0.3 published without. The plugin works the same as before.

## [1.0.3] - 2026-11-24

### Changed

- The store page shows screenshots of the plugin instead of a banner. The plugin works the same as before.

## [1.0.2] - 2026-11-24

### Fixed

- Channel names are cleaned in the channel list too, and stay clean when a channel is created or edited.

## [1.0.1] - 2026-11-14

### Fixed

- Discord no longer freezes while it sorts or searches many channels: each name is cleaned once, not on every read.

## [1.0.0] - 2026-11-14

### Added

- Initial release, after Equicord's CleanChannelName and the Dashless plugin for Vendetta: channel names show without dashes, emoji and decorative letters.
