## :sparkle: What it does

- :msgs: Long-press a message and pick **Select Messages**; tap another message to select everything between the two.
- :clipboard: **Copy** puts the whole run on the clipboard as `[time] Author: text`, one message per line.
- :clock: Runs that cross midnight get the date too; attachments are copied as links.
