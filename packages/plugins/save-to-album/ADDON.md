## :sparkle: What it does

- :photo: Every image or video you save from Discord's media viewer also goes into a Photos album of its own, "Discord" unless you name another.
- :gear: The album is made on the first save. Discord still saves as usual; the plugin only files the new item.
- :bell: Needs full Photos access, which iOS asks for on the first save if Discord only had permission to add photos.
