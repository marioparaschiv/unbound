## :sparkle: What it does

- :photo: Profiles and chat show the avatar a user set on UserPFP, animated when Discord animates avatars.
- :circle-info: Request your own in the UserPFP server, linked from github.com/UserPFP/UserPFP.
- :code-fork: A port of nexpid's UserPFP for Revenge.

## :gear: Settings

- **Prefer animated Nitro avatars:** when someone already has an animated Nitro avatar, show it.
