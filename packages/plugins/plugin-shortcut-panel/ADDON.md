## :sparkle: What it does

- :grid: A shortcuts button in the chat input opens one compact panel with the shortcuts you pinned.
- :toggle: A plugin shortcut turns that plugin on or off; it's highlighted while the plugin is on.
- :command: A command shortcut runs a plugin's slash command that needs no options, like `/follow-ups`, in the channel you're in.
- :pen: Tap **Edit** to pin or unpin any plugin or command. Shortcuts keep the order you pinned them in.
