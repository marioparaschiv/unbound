# Changelog

## [1.2.0] - 2026-11-18

### Added

- A Keep beside the chat input list in Edit mode, to choose which chat input buttons stay in the input instead of moving into the panel.

### Changed

- Chat input buttons show as rows with their names; pressing one closes the panel before it runs, so what it opens is no longer hidden behind the panel. Toggles show as switches.

## [1.1.0] - 2026-11-17

### Added

- Collects the buttons other plugins add to the chat input into the panel, so the input shows only the shortcuts button.

### Changed

- Pinned plugins are switches that show whether each plugin is on.

## [1.0.1] - 2026-11-17

### Fixed

- Its chat input button folds into the shared plugin button when the row is too narrow, so the send button stays on screen.

## [1.0.0] - 2026-11-16

### Added

- Adds a shortcuts button to the chat input that opens your pinned plugin toggles and plugin commands in one compact panel.
