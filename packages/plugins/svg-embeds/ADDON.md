## :sparkle: What it does

- :photo: SVG attachments show in chat as pictures, right where Discord would show any other image, instead of as a file of code.
- :circle-check: Each SVG is drawn once on your device, with iOS's own SVG renderer or an off-screen web view on Android, after scripts, event handlers and embedded HTML are stripped.
- :circle-info: SVGs up to 2 MB.
