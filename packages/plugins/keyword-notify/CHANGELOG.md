# Changelog

## [1.2.3] - 2026-11-26

### Fixed

- Text renders in Discord's font again. Discord renamed its text styles, so text using the old names fell back to the system font.

## [1.2.2] - 2026-11-24

### Fixed

- The store page shows the plugin's screenshots, which 1.2.1 published without. The plugin works the same as before.

## [1.2.1] - 2026-11-24

### Changed

- The store page shows screenshots of the plugin instead of a banner. The plugin works the same as before.

## [1.2.0] - 2026-11-16

### Added

- Keyword messages show up in the bell's notifications and in recent mentions, and stay there after Discord reloads them or restarts, until you remove them.

## [1.1.1] - 2026-11-13

### Changed

- Credits camila314, x3rt, benjas333, who made Equicord's KeywordNotify, which this ports.

## [1.1.0] - 2026-11-13

### Added

- Ignored users, channels (or whole categories) and servers, picked from searchable lists, where keywords never count as mentions.

### Changed

- Keywords are an ordered list you can rearrange.

## [1.0.0] - 2026-11-13

### Added

- Messages with your keywords count as mentions of you, in new messages and loaded history.
