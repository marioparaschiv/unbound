That avatar deserves a closer look. View Icons opens user and server images in Discord's media viewer, at full size.

## :sparkle: What it does

- :user: **View Avatar** and **View Banner** for a user, plus **View Server Avatar** when they have one in the server you're viewing.
- :server: **View Server Icon** and **View Server Banner** for a server.
- :users: **View Group DM Icon** for a group DM.
- :cursor-default: Rows sit in profile and server action sheets and in long-press menus, and appear only when that image is set.
- :magnifier-plus: Images load from Discord's CDN at 4096 pixels, as a GIF when animated.

## :gear: Settings

None. The rows show up wherever there's an image to open.
