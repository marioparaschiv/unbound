## :sparkle: What it does

- :link: Links to sites Discord does not know open straight away, without the "Leaving Discord" check.
- :download: Files Discord calls potentially dangerous download without the warning first.
- :code-fork: A port of Vencord's AlwaysTrust.

## :gear: Settings

- **Trust every link:** skips the check before opening a link to an unknown site.
- **Trust every download:** skips the warning before downloading a file Discord flags.
