# Changelog

## [1.1.0] - 2026-11-14

### Added

- Stickers you can't send in the current channel leave the sticker picker too, and a server section left empty disappears.
- Switches for emojis and stickers.

### Changed

- Renamed from Hide Unusable Emojis; the old plugin moves over by itself.

### Added
