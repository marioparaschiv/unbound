## :sparkle: What it does

- :eye-slash: An **Unsuppress Embeds** row in a message's long-press menu brings back link embeds that were removed from it.
- :eye-slash: On a message that shows embeds, the row reads **Suppress Embeds** and removes them instead.
- :share-up-right: Forwarded messages count too: the row shows when the forwarded message carries embeds.
- :arrow-down: The row sits just above **Delete Message**, in the same group. On a sheet without Delete it goes at the end of the first group.
- :code-fork: A port of Vencord's UnsuppressEmbeds.

## :lock: When the row shows

- :user: On your own messages, in servers where you can embed links and in DMs.
- :shield: On other people's messages, only in servers where you can manage messages, since Discord refuses the change otherwise.

If Discord refuses the change anyway, a toast says why.

## :gear: Settings

None. Long-press a message and look.
