# Changelog

## [1.0.4] - 2026-11-24

### Fixed

- The store page shows the plugin's screenshots, which 1.0.3 published without. The plugin works the same as before.

## [1.0.3] - 2026-11-24

### Changed

- The store page shows screenshots of the plugin instead of a banner. The plugin works the same as before.

## [1.0.2] - 2026-11-24

### Fixed

- System messages such as pins get no receipt, and the receipt stays on the last line of a subtext, heading or quote. Messages ending in a code block or list get none.

## [1.0.1] - 2026-11-16

### Changed

- Marks sit right after the message as small grey ticks, like chat apps show them, instead of in brackets next to "edited".

## [1.0.0] - 2026-11-16

### Added

- Marks your messages as sending, failed, or acknowledged by Discord's server. It can't tell whether anyone has read them.
