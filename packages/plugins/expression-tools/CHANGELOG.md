# Changelog

## [1.0.7] - 2026-11-13

### Fixed

- The clone sheet, its server list and the action bar use Discord's sheet header, text fields, table rows and buttons, and follow the theme.

## [1.0.6] - 2026-11-11

### Changed

- Needs Unbound 3.0.0 or newer. The plugin was reorganised for it and works the same as before.

## [1.0.5] - 2026-11-04

### Changed

- The buttons, toasts and the clone sheet can now be translated.
- The buttons come back on sticker and emoji sheets after the plugin is turned off and on again, and one sheet that fails to patch no longer takes the other sheet's buttons with it.

## [1.0.4] - 2026-11-03

### Changed

- Remove the opening line from the plugin's page on unbound.rip. The plugin works the same as before.

## [1.0.3] - 2026-11-03

### Changed

- Rewrite the plugin's page on unbound.rip in a shorter style. The plugin works the same as before.

## [1.0.2] - 2026-11-01

### Changed

- Starts once Discord has drawn its first frame, so it no longer delays Discord opening.

## [1.0.1]

### Changed

- Add a description and a changelog to the plugin's page on unbound.rip. The plugin works the same as in 1.0.0.

## [1.0.0] - 2026-10-25

### Added

- Initial release.
