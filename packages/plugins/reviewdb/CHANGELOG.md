# Changelog

## [2.0.0] - 2026-11-13

### Changed

- Reviews open from a Reviews section in the profile's About card, styled like Discord's own sections, instead of a button.
- The reviews sheet uses Discord's sheet header, notices, text area and buttons; reviews read like messages, with thumbs for votes and long-press actions in Discord's action sheet.

### Removed

- Theme reviews with the profile: the sheet follows Discord's theme.

## [1.1.0] - 2026-11-13

### Added

- Hide the ReviewDB notice: hides the warning above every list of reviews.
- Theme reviews with the profile: tints the reviews sheet, its text box and send button with the profile's theme colors, including ones from Fake Profile Themes.

## [1.0.6] - 2026-11-11

### Changed

- Needs Unbound 3.0.0 or newer. The plugin was reorganised for it and works the same as before.

## [1.0.5] - 2026-11-04

### Changed

- Every label, button and message in the plugin can now be translated. Your saved choices and sign-in carry over.
- The settings screen now lists Preferences first, then Account and Links.

### Fixed

- One review now reads "1 review" instead of "1 reviews".

## [1.0.4] - 2026-11-03

### Changed

- Remove the opening line from the plugin's page on unbound.rip. The plugin works the same as before.

## [1.0.3] - 2026-11-03

### Changed

- Rewrite the plugin's page on unbound.rip in a shorter style. The plugin works the same as before.

## [1.0.2] - 2026-11-01

### Changed

- Starts once Discord has drawn its first frame, so it no longer delays Discord opening.

## [1.0.1]

### Changed

- Add a description and a changelog to the plugin's page on unbound.rip. The plugin works the same as in 1.0.0.

## [1.0.0] - 2026-10-25
