# Changelog

## [1.1.0] - 2026-11-14

### Added

- Custom folder icons, after sadan's CustomFolderIcons for Equicord: long-press a folder to set a photo as its icon, or remove it.
- Changing **Hide server icons on closed folders** redraws the folders straight away.

## [1.0.0] - 2026-11-14

### Added

- Initial release, ported from Vencord's BetterFolders and fres's BetterFolders for Vendetta: close other folders when one opens, and an optional folder icon instead of server icons on closed folders.
