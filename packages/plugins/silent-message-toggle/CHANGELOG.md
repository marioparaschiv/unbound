# Changelog

## [1.1.1] - 2026-11-14

### Fixed

- The chat input toggle is the same grey as Discord's own buttons while off, instead of white.

## [1.1.0] - 2026-11-14

### Changed

- The toggle hides while the message box is empty unless it is on, and moves into a grid above the send button once a draft runs long.

## [1.0.3] - 2026-11-12

### Changed

- The toggle now shares its code with Aussie Speech's. It works the same as before.

## [1.0.2] - 2026-11-11

### Changed

- Needs Unbound 3.0.0 or newer. The plugin was reorganised for it and works the same as before.

## [1.0.1] - 2026-11-04

### Changed

- The button's label, the toast it shows and the settings screen can now be translated. The plugin works the same as before.

## [1.0.0] - 2026-11-03

### Added

- Initial release, ported from Vencord's SilentMessageToggle.
