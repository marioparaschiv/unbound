## :sparkle: What it does

- :at-sign: Asks before you send a message that pings @everyone or @here, so a stray ping doesn't reach a whole server.
- :users: Also asks when one message mentions many people or roles at once.
- :pen: **Keep editing** puts the message back in the chat input, with its reply, so nothing is lost.
- :code: Mentions inside code blocks and inline code don't count, since Discord pings nobody there.
- :shield: @everyone and @here only ask where you're allowed to ping everyone; elsewhere they ping nobody.

## :gear: Settings

- :at-sign: **Ask before @everyone and @here**: on by default.
- :users: **Ask from this many people**: 5 by default.
- :tag: **Ask from this many roles**: 2 by default.
