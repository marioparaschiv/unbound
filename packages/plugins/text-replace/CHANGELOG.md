# Changelog

## [1.1.2] - 2026-11-24

### Fixed

- The store page shows the plugin's screenshots, which 1.1.1 published without. The plugin works the same as before.

## [1.1.1] - 2026-11-24

### Changed

- The store page shows screenshots of the plugin instead of a banner. The plugin works the same as before.

## [1.1.0] - 2026-11-24

### Changed

- The settings list the rules first, then the tester and sharing. The tester stays open, Add rule rows have a plus icon, and the repeated title is gone.

### Removed

- The Paste JSON field and Import pasted button. Copy the JSON and use Import clipboard instead.

## [1.0.5] - 2026-11-11

### Changed

- Needs Unbound 3.0.0 or newer. The plugin was reorganised for it and works the same as before.

## [1.0.4] - 2026-11-04

### Changed

- The settings screen and its messages can now be translated. The import and share messages show as toasts with an icon, and a failed import shows the reason under "Could not import ruleset.". Your rules carry over.

## [1.0.3] - 2026-11-03

### Changed

- Rewrite the plugin's page on unbound.rip in a shorter style. The plugin works the same as before.

## [1.0.2] - 2026-11-01

### Changed

- Starts once Discord has drawn its first frame, so it no longer delays Discord opening.

## [1.0.1]

### Changed

- Add a description and a changelog to the plugin's page on unbound.rip. The plugin works the same as in 1.0.0.

## [1.0.0] - 2026-10-25

### Added

- Initial release.
