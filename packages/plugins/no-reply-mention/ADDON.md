When you start a reply, No Reply Mention sets the reply to not mention the author of the message you reply to. With **Only Ping Listed Users** on, replies to the users on your list still mention them.

## Settings

The settings panel has one group, **Exceptions**.

- **Add user ID** opens a field for a Discord user ID, with **Save** and **Cancel** buttons. The plugin accepts an ID of 15 to 25 digits. For any other text, it shows the toast "Enter a numeric Discord user ID." Each saved ID shows as a row with **Edit** and **Delete** buttons. The list is empty by default.
- **Only Ping Listed Users** (off by default) lets replies mention the users on the list. When it is on, a reply to a listed user mentions them, and a reply to anyone else does not. When it is off, no reply mentions its author and the list has no effect.
