## :sparkle: What it does

- :photo: Long-press a message with an image and pick **Make Emoji Mosaic**.
- :pen: Choose how many columns; rows follow the image's shape. Name the set, pick a server where you can add emoji.
- :msg: The tiles upload one by one, then the mosaic, one row per line, lands in your message box ready to send.

## :gear: Settings

None. Only servers where you have permission to add emoji, and enough free slots, can be picked.
