# Changelog

## [1.2.2] - 2026-11-17

### Fixed

- Its chat input button folds into the shared plugin button when the row is too narrow, so the send button stays on screen.

## [1.2.1] - 2026-11-14

### Fixed

- The chat input's plugin buttons fold behind one button once the draft spans lines or leaves no room, instead of jumping into a grid while you type.

## [1.2.0] - 2026-11-14

### Changed

- The timestamp button hides while the message box is empty, and moves into a grid above the send button once a draft runs long.

## [1.1.1] - 2026-11-13

### Fixed

- The chat input clock is the same size and colour as Discord's emoji and voice buttons.

## [1.1.0] - 2026-11-13

### Added

- A clock in the chat input that picks a date and time, previews every style and inserts or copies the timestamp, like Vencord's picker.

## [1.0.0] - 2026-11-13

### Added

- Initial release, ported from Vencord's SendTimestamps.
