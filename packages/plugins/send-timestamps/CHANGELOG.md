# Changelog

## [1.3.2] - 2026-11-24

### Fixed

- The store page shows the plugin's screenshots, which 1.3.1 published without. The plugin works the same as before.

## [1.3.1] - 2026-11-24

### Changed

- The store page shows screenshots of the plugin instead of a banner. The plugin works the same as before.

## [1.3.0] - 2026-11-24

### Changed

- The timestamp sheet uses Discord's sheet header: Pick a timestamp, then Tap a style to insert it.

## [1.2.4] - 2026-11-18

### Changed

- Shows as a row in the Plugin Shortcut Panel that closes the panel before it runs, and can stay beside the chat input from the panel's Edit list.

## [1.2.3] - 2026-11-17

### Changed

- Its chat input button moves into the Plugin Shortcut Panel while that plugin is on.

## [1.2.2] - 2026-11-17

### Fixed

- Its chat input button folds into the shared plugin button when the row is too narrow, so the send button stays on screen.

## [1.2.1] - 2026-11-14

### Fixed

- The chat input's plugin buttons fold behind one button once the draft spans lines or leaves no room, instead of jumping into a grid while you type.

## [1.2.0] - 2026-11-14

### Changed

- The timestamp button hides while the message box is empty, and moves into a grid above the send button once a draft runs long.

## [1.1.1] - 2026-11-13

### Fixed

- The chat input clock is the same size and colour as Discord's emoji and voice buttons.

## [1.1.0] - 2026-11-13

### Added

- A clock in the chat input that picks a date and time, previews every style and inserts or copies the timestamp, like Vencord's picker.

## [1.0.0] - 2026-11-13

### Added

- Initial release, ported from Vencord's SendTimestamps.
