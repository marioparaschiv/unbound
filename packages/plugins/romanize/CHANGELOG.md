# Changelog

## [1.1.3] - 2026-11-26

### Fixed

- Text renders in Discord's font again. Discord renamed its text styles, so text using the old names fell back to the system font.

## [1.1.2] - 2026-11-24

### Fixed

- The store page shows the plugin's screenshots, which 1.1.1 published without. The plugin works the same as before.

## [1.1.1] - 2026-11-24

### Changed

- The store page shows screenshots of the plugin instead of a banner. The plugin works the same as before.

## [1.1.0] - 2026-11-24

### Changed

- The romanize dialog shows the original message under the romanized text.

## [1.0.1] - 2026-11-19

### Changed

- Hindi and other Devanagari messages are recognised from their first letter, with the script ranges written as plain escapes.

## [1.0.0] - 2026-11-19

### Added

- Initial release: long-press a message to read it in Latin letters. Korean follows the Revised Romanization of Korean with its sound changes; other scripts use the phone's own transliteration.
