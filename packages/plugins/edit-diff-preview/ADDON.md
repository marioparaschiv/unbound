## :sparkle: What it does

- :pen: When you save an edit, shows what changed before Discord saves it: removed text struck through in red, added text in green.
- :scroll-y: Long unchanged stretches shrink to their ends, so the changes stay in view; long diffs scroll.
- :undo: **Keep editing** reopens the edit with your new text, so nothing is lost.
- :code: Meant for long messages and code, where a stray paste or deletion is easy to miss.

## :gear: Settings

- :ruler: **Show from this many characters**: 200 by default. Edits to shorter messages save straight away; 0 shows every edit.
- :code: **Always show for code**: on by default, for messages with a code block of any length.
