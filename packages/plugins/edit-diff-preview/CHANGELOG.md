# Changelog

## [1.0.5] - 2026-11-26

### Fixed

- Text renders in Discord's font again. Discord renamed its text styles, so text using the old names fell back to the system font.

## [1.0.4] - 2026-11-24

### Fixed

- Editing works again on recent Discord builds. Saved edits no longer get lost.

## [1.0.3] - 2026-11-24

### Fixed

- The store page shows the plugin's screenshots, which 1.0.2 published without. The plugin works the same as before.

## [1.0.2] - 2026-11-24

### Changed

- The store page shows screenshots of the plugin instead of a banner. The plugin works the same as before.

## [1.0.1] - 2026-11-24

### Fixed

- The diff uses Discord's message font, and code messages are compared in a code font without their ``` fences.

## [1.0.0] - 2026-11-16

### Added

- Shows what an edit adds and removes before it is saved, for long messages and code.
