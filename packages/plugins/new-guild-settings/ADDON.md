## :sparkle: What it does

- :bell-slash: When you join a server, it is muted and set to your notification defaults as soon as you join.
- :user-plus: Works for invites, for **Join** on a server you are previewing from Discovery, and for join requests a server approves.
- :eye: Turns on **Show All Channels** in servers that let you pick channels, so none stay hidden.
- :cursor-default: Long-press a server for **Apply New Guild Settings** to apply the same defaults to a server you are already in.
- :circle-info: Your choices are saved to your account through Discord's own notification settings, so they show up on desktop too.
- :code-fork: A port of Vencord's NewGuildSettings.

## :gear: Settings

All switches are on by default.

- :bell-slash: **Mute Server**: mutes the server.
- :at-sign: **Suppress @everyone and @here** and **Suppress All Role @mentions**.
- :bell: **Suppress Highlights**: turns off highlight notifications.
- :calendar: **Mute New Events**: mutes scheduled event notifications.
- :eye: **Show All Channels**: shows every channel in servers with channel picking.
- :gear: **Server Notification Settings**: **All Messages**, **Only @mentions**, **Nothing**, or **Server Default**, which leaves the server's own default alone.

## :circle-info: Differences from Vencord

- :mobile: Desktop's server right-click menu and server header menu become the server long-press sheet and context menu on mobile.
- :circle-check: Accepting an invite to a server you are already in leaves its settings alone.
