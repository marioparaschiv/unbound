## :sparkle: What it does

- :bell: Notifies you of mentions and DMs on iOS installs where Discord's push notifications never arrive, such as sideloaded builds without the push entitlement.
- :gear: Keeps Discord connected while it is in the background with a silent sound, restarted after calls and checked every minute, and posts the notifications itself.
- :text: Tapping a notification opens its chat. Notifications from the same chat stack together.
- :photo: Automatic mode runs only when this install cannot receive push; Always runs it everywhere.
