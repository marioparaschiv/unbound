## :sparkle: What it does

- :text-size-change: Math written in TeX shows as readable symbols: `$x^2 + \sqrt{y} \leq \pi$` reads **x² + √y ≤ π**.
- :circle-check: Works with `$…$`, `$$…$$`, `\(…\)` and `\[…\]`. Single dollar signs only count when the text inside has `\`, `^`, `_` or `=`, so prices like $5 stay as written.
- :files: Code blocks, inline code and links are left alone, and the message itself keeps its TeX.

Inspired by Aly's KaTeX extension for moonlight.
