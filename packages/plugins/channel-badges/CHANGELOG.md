# Changelog

## [1.2.1] - 2026-11-24

### Changed

- The store page shows screenshots of the plugin instead of a banner. The plugin works the same as before.

## [1.2.0] - 2026-11-24

### Changed

- Badges use Discord's own badge styles, so they match your theme. Type and Private badges are now grey.

## [1.1.1] - 2026-11-17

### Changed

- Badges use Discord's theme colours, so custom and Nitro themes recolour them.

## [1.1.0] - 2026-11-15

### Changed

- Locked now marks channels you cannot post or talk in, instead of every private channel.

### Added

- A Private badge for channels hidden from @everyone.

## [1.0.0] - 2026-11-14

### Added

- NSFW, Locked and Rules badges, and optional type badges, on channels in the channel list.
