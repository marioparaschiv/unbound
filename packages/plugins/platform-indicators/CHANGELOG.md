# Changelog

## [1.0.2] - 2026-11-11

### Changed

- Needs Unbound 3.0.0 or newer. The plugin was reorganised for it and works the same as before.

## [1.0.1] - 2026-11-04

### Changed

- The settings screen, the platform names and the screen reader text can now be translated, and the screen reader text joins the platforms in the language of the plugin's own strings. If one place cannot show indicators after a Discord update, the others still do.

## [1.0.0] - 2026-11-03

### Added

- Initial release, ported from Vencord's PlatformIndicators.
