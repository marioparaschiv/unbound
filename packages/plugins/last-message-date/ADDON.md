## :sparkle: What it does

- :clock: Profiles show a **Last Message** section: when the user last sent a message in the server you're in, or in your DMs, such as "3 days ago in #general".
- :link: Tap it to jump to that message.
- :circle-info: It asks Discord's search once per profile, so it works for messages you never loaded.
- :code-fork: After fres's LastMessageDate for Vendetta.
