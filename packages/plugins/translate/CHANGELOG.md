# Changelog

## [1.2.0] - 2026-11-10

### Added

- A **Show languages** setting for translations in the message. Turn it off to leave out the languages, such as `(en -> de)`.
- A **Show languages as flags** setting, which shows the languages as flag emojis where a language has one, such as `(🇬🇧 -> 🇩🇪)`.

### Changed

- A translation in the message now follows the original text directly, without an empty line between them.

## [1.1.0] - 2026-11-10

### Added

- A **Show Translations** setting. Pick **In the message** to show the translation under the message's text, as small italic text ending with the language codes, such as `(en -> de)`, instead of copying it and showing a toast.
- On a message translated in the chat, the long-press menu offers **Show Original**, which removes the translation. Editing the message also removes it.

## [1.0.4] - 2026-11-05

### Changed

- The Translate row, the settings screen, the language picker and the toasts can now be translated. The plugin works the same as before.

## [1.0.3] - 2026-11-03

### Changed

- Rewrite the plugin's page on unbound.rip in a shorter style. The plugin works the same as before.

## [1.0.2] - 2026-11-01

### Changed

- Starts once Discord has drawn its first frame, so it no longer delays Discord opening.

## [1.0.1]

### Changed

- Add a description and a changelog to the plugin's page on unbound.rip. The plugin works the same as in 1.0.0.

## [1.0.0] - 2026-10-25

### Added
