Show Me Your Name adds the account's username to the author name above each message in a chat. For example, a message from Alice whose username is alice99 shows as "Alice (@alice99)".

The plugin leaves the name alone when the name Discord shows is already the username. It also skips AutoMod messages.

## Settings

- **Display Mode** picks the format of the author name. The options are **Display name then username** ("Display Name (@username)"), **Username then display name** ("@username (Display Name)"), and **Username only** ("@username"). The default is **Display name then username**.
- **Show Friend Nicknames** uses the nickname you gave a friend in place of the name Discord shows. On by default.
- **Use Global Names** shows the account's global name after the @ in place of its username. Off by default.
- **Apply To Replies** also changes the author name in the preview of the message a reply answers. Off by default.
