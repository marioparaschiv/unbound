Who is "Alice", really? Show Me Your Name adds the username next to the author name on each message, so "Alice" reads "Alice (@alice99)".

## :sparkle: What it does

- :at-sign: Adds the account's username to the author name above each message.
- :user-check: Leaves the name alone when Discord already shows the username.
- :chat-bot: Skips AutoMod messages.

## :gear: Settings

- :text: **Display Mode** picks the format: **Display name then username**, **Username then display name**, or **Username only**. **Display name then username** by default.
- :user-heart: **Show Friend Nicknames** uses the nickname you gave a friend in place of the name Discord shows. On by default.
- :users: **Use Global Names** shows the global name after the @ in place of the username. Off by default.
- :undo: **Apply To Replies** also changes the name in a reply's preview of the message it answers. Off by default.
