# Changelog

## [1.0.2] - 2026-11-11

### Changed

- Needs Unbound 3.0.0 or newer. The plugin was reorganised for it and works the same as before.

## [1.0.1] - 2026-11-05

### Changed

- The settings labels and the switch in the upload preview sheet can now be translated. The plugin works the same as before.

### Fixed

- A different upload preview sheet layout no longer stops files from being sent under anonymous names.

## [1.0.0] - 2026-11-03

### Added

- Initial release, ported from Vencord's AnonymiseFileNames.
