## :sparkle: What it does

- :msgs: Draws the linked message as a Discord chat row, on a new line after the channel mention Discord shows for the link.
- :link: Reads links from discord.com and discordapp.com, subdomains included.
- :refresh: Fetches the linked message from Discord if it isn't loaded yet, then adds the preview when it arrives.
- :video: GIFs, animated emoji and animated stickers play without a tap, and Lottie animations loop.
- :arrow-down: On iOS, a chat sitting at its bottom stays there when a preview loads or changes height.

## :gear: Settings

None. Paste a message link and the preview follows.
