# Changelog

## [1.0.2] - 2026-11-11

### Changed

- Needs Unbound 3.0.0 or newer. The plugin was reorganised for it and works the same as before.

## [1.0.1] - 2026-11-04

### Changed

- The button's accessibility label and the message shown when the window doesn't start can now be translated. The plugin works the same as before.

## [1.0.0] - 2026-11-04

### Added

- Initial release, ported from Vencord's PictureInPicture: picture in picture for attachments, video embeds and web players such as YouTube, on iOS and Android.
