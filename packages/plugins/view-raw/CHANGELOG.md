# Changelog

## [1.0.6] - 2026-11-11

### Changed

- Needs Unbound 3.0.0 or newer. The plugin was reorganised for it and works the same as before.

## [1.0.5] - 2026-11-05

### Changed

- The View Raw row, the raw data sheet and its copy notices can now be translated.
- The View Raw item in a profile's overflow menu now shows in every language, not just English. If Discord's translation of "View Main Profile" cannot be read, the plugin falls back to the English label.

## [1.0.4] - 2026-11-03

### Changed

- Rewrite the plugin's page on unbound.rip in a shorter style. The plugin works the same as before.

## [1.0.3] - 2026-11-01

### Changed

- Starts once Discord has drawn its first frame, so it no longer delays Discord opening.

## [1.0.2]

### Fixed

- The **View Raw** row now appears in the long-press menu of a channel or a thread on Android.

## [1.0.1]

### Changed

- Add a description and a changelog to the plugin's page on unbound.rip. The plugin works the same as in 1.0.0.

## [1.0.0] - 2026-10-25

### Added

- Initial release.
