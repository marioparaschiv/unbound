# Changelog

## [1.0.6] - 2026-11-26

### Fixed

- A message box that grows, for more lines or more buttons, keeps rounded corners instead of turning into an oval that cuts off the send button.
- The voice channel controls sheet keeps Discord's corners instead of an oval that cuts off its top.

## [1.0.5] - 2026-11-24

### Fixed

- The store page shows the plugin's screenshots, which 1.0.4 published without. The plugin works the same as before.

## [1.0.4] - 2026-11-24

### Changed

- The store page shows screenshots of the plugin instead of a banner. The plugin works the same as before.

## [1.0.3] - 2026-11-24

### Fixed

- The chat input is fully round instead of only slightly rounded.

## [1.0.2] - 2026-11-17

### Fixed

- The You bar keeps its shape under a quest banner: corners Discord squares to join the banner stay square.

## [1.0.1] - 2026-11-15

### Fixed

- The You bar's left corners are fully round: its shape comes from a masked background whose own corner radii were left at 28.
- Components rounded by more than one target are no longer rounded once per target on every render.

## [1.0.0] - 2026-11-14

### Added

- Rounds server icons, server bar buttons, chat bar buttons, the You bar, the message box and the Quests, Shop and Settings bar, and restores older corners elsewhere, each behind its own switch.
