## :sparkle: What it does

- :command: Long-press a bot's reply to a slash command and pick **Copy Command Mention** to copy its clickable mention, like `</ping:123>`.
- :brackets-curly: Subcommands work too: `</ban user:123>`.
- :magnifier: The command id comes from the server's or DM's command list, then from apps you added to your account.
