## :sparkle: What it does

- :text-color: Lines that start with `>`, like `>be me`, show in green, the way imageboards draw greentext.
- :msg: Discord's own quotes, written `> ` with a space, stay as they are, and so do code blocks.

## :gear: Settings

- **Color**: pick your own color instead of imageboard green.
