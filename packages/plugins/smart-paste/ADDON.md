## :sparkle: What it does

- :clipboard: Adds a paste button to the chat input. Tap it to paste what you copied in the form you need:
    - :text: **Plain text**, with markdown characters escaped so `**this**` shows as written.
    - :code: **Code block**, fenced so backticks inside it stay intact.
    - :msg: **Quote**, with every line quoted.
    - :link-slash: **Link without a preview** for a single link, wrapped in `< >` so Discord shows no embed.
    - :paperclip: **Text file** for long or multi-line text, attached as `message.txt` like Discord desktop does with long pastes.
- :mobile: On iOS the button sits with the chat input's other buttons. On Android it sits next to the send button, so it shows up once you start typing.
