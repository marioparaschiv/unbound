# Changelog

## [1.0.3] - 2026-11-17

### Changed

- Its chat input button moves into the Plugin Shortcut Panel while that plugin is on.

## [1.0.2] - 2026-11-17

### Fixed

- Its chat input button folds into the shared plugin button when the row is too narrow, so the send button stays on screen.

## [1.0.1] - 2026-11-16

### Fixed

- Shows a warning instead of an error toast when pasting as a text file fails.

## [1.0.0] - 2026-11-16

### Added

- Adds a paste button to the chat input that pastes the clipboard as plain text, a code block, a quote, a link without a preview, or a text file.
