# Changelog

## [1.1.2] - 2026-11-14

### Fixed

- The pill no longer covers another tag in the header, such as a server role tag: those headers show the pronouns after the timestamp instead.

## [1.1.1] - 2026-11-13

### Fixed

- The pill keeps its text readable under themes: when a theme makes the pill's text and background too close, the text turns black or white.

## [1.1.0] - 2026-11-13

### Added

- Style: show pronouns in a pill like Discord's OP tag, in Discord's tag colors or a color you pick. Android keeps Discord's tag colors.

## [1.0.4] - 2026-11-11

### Changed

- Needs Unbound 3.0.0 or newer. The plugin was reorganised for it and works the same as before.

## [1.0.3] - 2026-11-05

### Changed

- The settings labels and the names of pronoun sets, such as "Ask me my pronouns", can now be translated. The plugin works the same as before.

## [1.0.2] - 2026-11-03

### Changed

- Rewrite the plugin's page on unbound.rip in a shorter style. The plugin works the same as before.

## [1.0.1]

### Changed

- Add a description and a changelog to the plugin's page on unbound.rip. The plugin works the same as in 1.0.0.

## [1.0.0] - 2026-10-25

### Added

- Initial release.
