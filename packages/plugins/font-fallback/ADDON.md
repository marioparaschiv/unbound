## :sparkle: What it does

- :globe: Gives each writing system in messages its own font: Japanese in one, Korean in another, Latin left as Discord draws it.
- :msgs: Mixed-language messages switch fonts mid-line, word by word, without forcing one font on everything.
- :code: Code blocks keep their monospace font.

## :gear: Settings

Pick a font for each writing system from the fonts installed in Unbound's **Fonts** settings.
