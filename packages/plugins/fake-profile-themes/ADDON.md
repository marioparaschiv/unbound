## :sparkle: What it does

- :paint-palette: Profiles whose bio hides theme colors with the 3y3 code show those colors, the same code Vencord users write.
- :copy: Pick two colors in the settings and copy the invisible code to paste at the end of your own bio.
- :code-fork: A port of Vencord's FakeProfileThemes.

## :gear: Settings

- **Prefer Nitro colors:** when a profile has Nitro theme colors and hidden ones, show the Nitro colors.
- **Primary** and **Accent:** the colors for your own code.
- **Copy bio code:** copies the invisible code to paste at the end of your bio.
