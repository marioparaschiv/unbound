# Changelog

## [1.1.0] - 2026-11-24

### Changed

- Editing opens Discord's dialog with a text area, Save, Restore Original and Cancel, instead of a sheet.

### Added

- Edit Locally in the message long-press menu changes what a message says on this device only.
