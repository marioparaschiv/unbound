## :sparkle: What it does

- :text-size-change: The message box shows your markdown as you type it, the way the message will look once sent: **bold**, _italics_, **underline**, ~~strikethrough~~, `code`, ||spoilers||, headings, subtext and quotes.
- :circle-check: The markers stay in place but fade, so editing stays easy, and nothing changes in the text you send.
- :circle-info: iOS only for now.
