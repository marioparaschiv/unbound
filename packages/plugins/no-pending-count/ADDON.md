## :sparkle: What it does

- :user-plus: Incoming friend requests no longer add a red count to the friends tab.
- :inbox: Message requests and spam requests no longer add a count to your messages.
- :circle-info: The requests themselves still arrive; only the counts go.
- :code-fork: A port of Vencord's NoPendingCount.

## :gear: Settings

- **Hide friend request count:** removes the count for incoming friend requests.
- **Hide message request count:** removes the count for message and spam requests.
