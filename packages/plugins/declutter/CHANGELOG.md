# Changelog

## [1.0.5] - 2026-11-17

### Changed

- Its chat input button moves into the Plugin Shortcut Panel while that plugin is on.

## [1.0.4] - 2026-11-17

### Fixed

- Keeps the send button whenever Discord can send, such as while editing a message or sending only a sticker.

## [1.0.3] - 2026-11-15

### Fixed

- Voice call buttons hides the call button on profiles again, where Discord moved it into a row beside Add Friend.

## [1.0.2] - 2026-11-14

### Fixed

- The chat input's plugin buttons fold behind one button once the draft spans lines or leaves no room, instead of jumping into a grid while you type.

## [1.0.1] - 2026-11-14

### Fixed

- Dropped a lookup for a module Discord does not have; the Nitro button is hidden by its icon, as before.

## [1.0.0] - 2026-11-14

### Added

- Declutter replaces Hide Buttons and keeps all of its options.
- New options, ported from Benjii's Declutter: avatar decorations, nameplates, profile effects, profile frames, profile badges, server tags, display name styles, the Wishlist and Activity profile tabs, server themes, DM activity cards, the Quest dock, the Nitro button and Orbs balance on the You screen, the boost goal bar, and the payment pages in User Settings.
