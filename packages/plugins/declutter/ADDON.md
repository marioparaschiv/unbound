## :sparkle: What it does

- :gift: Removes the gift, voice message and call buttons, and the send button while the message box is empty.
- :star: Removes Quests, Shop and Nitro from the You screen, the Orbs balance, the Quest dock, Server Boosts and the boost goal bar.
- :user: Hides avatar decorations, nameplates, profile effects, profile frames, profile badges, server tags and display name styles.
- :gear: Hides the Nitro, Shop, Quests, subscription, boost and gift pages in User Settings, and the Wishlist and Activity tabs on profiles.
- :circle-info: Every option has its own switch, so you only hide what you never use. It replaces Hide Buttons, which it grew out of.

## :gear: Settings

- **Gift button:** on by default, as in Hide Buttons.
- Everything else is off until you turn it on.
