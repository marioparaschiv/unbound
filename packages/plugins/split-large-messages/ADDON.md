## :sparkle: What it does

- :scissors: A message over Discord's length limit is sent as several messages, in order, instead of being refused.
- :jigsaw: Parts break at blank lines, lines, sentences or words, and a code block that spans parts is closed and reopened so each part still renders.

## :gear: Settings

- **Most parts**: how many messages one draft may become; longer drafts are refused as usual.
