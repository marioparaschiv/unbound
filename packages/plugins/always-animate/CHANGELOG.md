# Changelog

## [1.0.3] - 2026-11-11

### Changed

- Needs Unbound 3.0.0 or newer. The plugin was reorganised for it and works the same as before.

## [1.0.2] - 2026-11-04

### Changed

- The settings can now be translated. They show in one list instead of under Profiles, Servers and Expressions. Your choices carry over.

## [1.0.1] - 2026-11-04

### Fixed

- Animate profile effects on Android too, which uses its own profile effect layer.

## [1.0.0] - 2026-11-03

### Added

- Initial release, ported from Vencord's AlwaysAnimate.
