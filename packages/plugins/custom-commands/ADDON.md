## :sparkle: What it does

- :command: Your commands show in Discord's slash-command list, next to the built-in ones.
- :paperclip: Each command sends a saved response with up to 10 images or videos attached.
- :brackets-curly: Write `{{name}}` for a required argument or `{{name = default}}` for an optional one. Type `\n` for a line break.
- :msg-arrow-right: Run a command while replying and the response goes out as a reply.
- :eye: Every command has an `ephemeral` option that shows the response only to you. Commands with attachments can't use it.

## :gear: Settings

Tap **Create command** to add one, and edit or delete it under **Registered commands**. A command has a **Command name** (1 to 32 lowercase letters, numbers, hyphens or underscores), a **Description (optional)** of up to 100 characters, a **Response**, and **Attach media** for local images and videos. It needs a response, an attachment, or both.
