## :sparkle: What it does

- :code: Shows code with line numbers and syntax colors under a header with a language icon and name.
- :clipboard: **Copy** copies the code exactly as it was written between the fences.
- :scroll-y: Cards grow with their code up to a fixed height, then scroll.
- :globe: Grammars and themes download from jsDelivr when a block first needs them. A custom theme downloads from the URL you enter.

## :gear: Settings

- :palette: **Theme** picks from 61 VS Code themes. Dark Plus by default.
- :link: **Custom theme URL** loads an HTTPS theme JSON file and overrides **Theme**.
- :brackets-curly: **Language icons** cycles `disabled`, `greyscale` and `colored`. Greyscale by default.
- :scroll-x: **Long lines** picks **Wrap** or **Horizontal scroll**. Wrap by default.
- :sliders-3: **Background opacity (%)** and **Highlighting preference** tune the card and when Highlight.js takes over from Shiki.
