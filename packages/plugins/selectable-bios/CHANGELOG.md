# Changelog

## [1.0.3] - 2026-11-26

### Fixed

- Text renders in Discord's font again. Discord renamed its text styles, so text using the old names fell back to the system font.

## [1.0.2] - 2026-11-24

### Changed

- The store page no longer shows a banner. The plugin works the same as before.

## [1.0.1] - 2026-11-18

### Fixed

- Bios can actually be selected now: a long press on the bio turns it into selectable text in place, with the whole bio selected and handles to narrow it. Discord draws bios with a text view that ignores the selectable flag. Links stay tappable.

## [1.0.0] - 2026-11-17

### Added

- Initial release: profile bios can be selected and copied.
