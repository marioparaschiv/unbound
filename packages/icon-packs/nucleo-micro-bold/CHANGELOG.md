# Changelog

## [1.0.3]

### Added

- Draws the 19 brand logos Nucleo lacks (Discord, Steam, Xbox and the rest) as solid Micro Bold glyphs, instead of keeping Discord's.

## [1.0.2]

### Added

- Covers 129 more of Discord's icons, including the Marketplace shop icon.

## [1.0.1]

### Changed

- Icons built from a glyph and a small corner badge (lock, plus, warning and the like) draw the badge with the same stroke width as the glyph.

### Fixed

- Quests shows a rosette, matching Discord's laurel wreath, instead of a broken flag.

## [1.0.0]

### Added

- Initial release.
