<Note>
	Cloud Sync is not available yet. Opening it in the app shows **Coming Soon**.
</Note>

### Where to find it

Open Discord's settings, go to **General** in the **Unbound** section, and tap **Cloud Sync**.

### Until it's ready

Your addons and settings are stored only on the device you set them up on. To use the same setup on another device, install Unbound there and add the same addons from their links. See [Managing Addons](/user-guide/managing-addons).
