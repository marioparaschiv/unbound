---
title: 'Updating Unbound'
description: 'How Unbound keeps itself up to date, how to pick an older version, and how to update the app.'
icon: 'arrows-rotate'
---

Unbound has two parts that update separately:

- **The bundle** is Unbound itself, a single JavaScript file. It updates on its own every time you open Discord.
- **The app or tweak** is the modified Discord you installed. You update it the same way you installed it. On Android, the Unbound Manager can install these updates for you.

To see which bundle you're running, open the **General** page in the **Unbound** section of Discord's settings and look at the **Unbound** row under **Version Info**.

### Automatic bundle updates

You don't need to do anything. Each time Discord starts, the loader checks for a newer bundle and downloads it only if there is one. A new bundle is used on the same launch it was downloaded.

<Tabs>
	<Tab title='iOS'>
		If the check or download fails, Unbound loads the bundle that's already on your device. No message appears, so you just keep the version you had.

		If there is no bundle on the device at all, for example on the first launch without internet, Discord shows **Failed to load Unbound's bundle. Please report this to the developers.** and opens without Unbound. Connect to the internet and open Discord again.
	</Tab>
	<Tab title='Android'>
		If the check fails, Discord shows a dialog titled **Unbound** that reads **[Updater] Failed to check for updates, bundle may be out of date. Please report this to the developers.** Tap **Okay**. Unbound keeps running the bundle it already has.

		If a download fails, the dialog depends on whether an older bundle is on the device:

		- **Bundle failed to update, loading out of date bundle.** means Unbound loads the older bundle.
		- **Bundle failed to download, please report this to the developers.** means there is no bundle yet, and Discord opens without Unbound.

		These dialogs also show up when you open Discord without internet. See [Troubleshooting](/user-guide/troubleshooting#android-shows-an-unbound-error-dialog) for every message.
	</Tab>
</Tabs>

### Check for an update right away on iOS

Open the toolbox by shaking your device or holding three fingers on the screen, then tap **Refetch Bundle** in the **Bundle** section. It checks the current source, downloads the bundle if it changed, and restarts the app.

### Go back to an older version

This is only on iOS, through the toolbox. The Android loader doesn't have a toolbox yet, so it always uses the latest bundle.

<Steps>
	<Step title='Open the Toolbox'>
		Shake your device for half a second to two seconds, or hold three fingers on the screen for half a second.
	</Step>
	<Step title='Tap Switch Bundle Version'>
		It's in the **Bundle** section. Unbound looks up the available builds on GitHub, which needs an internet connection.
	</Step>
	<Step title='Pick a Branch'>
		If there is more than one branch, pick one under **Select Branch**. With only one branch, this step is skipped.
	</Step>
	<Step title='Pick a Version'>
		**Select Version** lists the branch's last 10 builds, each shown as a short code and a date, for example `a1b2c3d (Mar 4, 2026)`. Tap one. The app restarts on that build.
	</Step>
</Steps>

<Warning>
	A picked version stays pinned. Unbound downloads that same build on every launch and stops updating on its own until you go back to the official bundle.
</Warning>

If the list doesn't load, you see **Failed to fetch branches** or **Failed to fetch commits**. Check your connection and try again.

### Go back to the official bundle

Use this to undo **Switch Bundle Version** or **Load Custom Bundle**.

<Steps>
	<Step title='Open the Toolbox'>
		Shake your device or hold three fingers on the screen.
	</Step>
	<Step title='Tap Delete Bundle'>
		It's in the **Bundle** section and shown in red. Tap **Confirm**.
	</Step>
</Steps>

Unbound deletes the downloaded bundle, forgets the pinned version or custom source, and restarts. On the next launch it downloads the latest official bundle, so you need to be online. Your addons and settings stay.

### Update the app or tweak

When a new version of the app or tweak comes out, install it the same way you installed Unbound. The bundle updates on its own either way.

<Tabs>
	<Tab title='iOS'>
		#### Sideloaded from the source

		If you added Unbound's source to SideStore, Feather, AltStore, or another sideloading tool, the tool lists new versions of **Unbound** from that source. Refresh the source and install the update from there.

		#### Sideloaded from the app file

		Download the latest [Unbound.ipa](https://github.com/unbound-app/loader-ios/releases/latest/download/Unbound.ipa) again and install it with your sideloading tool, the same way you did the first time.

		#### Jailbroken

		<Steps>
			<Step title='Refresh Your Package Manager'>
				Open Sileo or your other package manager and refresh its sources.
			</Step>
			<Step title='Upgrade Unbound'>
				Install the update to the **Unbound** package when it shows up.
			</Step>
			<Step title='Restart Discord'>
				Close Discord if it was running, then open it again.
			</Step>
		</Steps>

		If you installed the package file instead of using the repo, download the newer `.deb` from the [latest GitHub release](https://github.com/unbound-app/loader-ios/releases/latest) and open it in your package manager.

		If Discord shows **This version of Discord is incompatible with this version of the Tweak.**, your Discord app is too old for the installed tweak. Update Discord from the App Store, then open it again.
	</Tab>
	<Tab title='Android'>
		#### With the Unbound Manager

		If you installed Unbound with the [Unbound Manager](/user-guide/installing), it checks for new builds every 6 hours, on the channel you picked.

		- If **Update automatically** is on and the manager installed the app, Android 12 and later install the update without asking you. The switch is on the manager's home screen, and it's on by default.
		- Otherwise the manager posts a notification with an **Update** button. Tap **Update** once to install.

		If an update fails while the manager is in the background, it posts a **Couldn't update** notification with the reason. Tap it to see the failed step, retry, or share the log.

		The manager updates itself the same way. When an update is waiting, the manager lists the changes in every release since the build you have.

		The notifications come in three channels: **Patched Discord updates**, **LSPosed module updates**, and **Manager updates**. You can turn each one off in Android's notification settings.

		<Note>
			On Android 13 and later, the manager needs the notification permission to tell you about updates. Allow it when the manager asks, or turn on notifications for **Unbound Manager** in Android's app settings.
		</Note>

		The manager never touches the bundle. The bundle keeps updating itself inside Discord, as described in [Automatic bundle updates](#automatic-bundle-updates).

		After the manager updates the Xposed module, force stop Discord from Android's app settings and open it again, so the new module loads.

		#### Patched Discord without the manager

		If you added Unbound to [Obtainium](/user-guide/installing), it shows an update when a new build for your channel is out. Tap **Update**. Stable, beta and alpha each get their own builds, so you only see updates for the channel you picked.

		If you installed a bundle from GitHub by hand, download the newer one for the same channel from the [GitHub releases](https://github.com/marioparaschiv/unbound/releases) and install it over the old one with your split-APK installer.

		#### Xposed module without the manager

		If you added the module to Obtainium, update it there. Otherwise download the newer `app.unbound.android.lsposed.apk` from the [latest release](https://github.com/marioparaschiv/unbound/releases/tag/loader-latest) and install it over the old one like any other Android app update.

		Then force stop Discord from Android's app settings and open it again, so the new module loads.
	</Tab>
</Tabs>
