<Note>
	The Marketplace is not available yet. Opening it in the app shows **Coming Soon**.
</Note>

### Where to find it

Open Discord's settings and go to **Marketplace** in the **Unbound** section, below **General**, **Plugins**, and **Design**.

### What it will do

The Marketplace is where you'll browse plugins, themes, and icon packs and install them without copying a link. It's planned on the [roadmap](/roadmap) as two parts:

- **Embedded Addon Store**: the store screen inside Discord.
- **Centralized Addon Store** and **Addon Submission**: the online catalog behind it, where developers publish their addons.

### Install addons today

Until the Marketplace is ready, install addons from a link. See [Install an addon](/user-guide/managing-addons#install-an-addon).
