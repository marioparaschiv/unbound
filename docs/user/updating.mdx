Unbound updates itself. The app you installed, you update by hand.

| Part | Updates |
| --- | --- |
| **Unbound** | On its own, each time Discord starts |
| **The app** | By you, the way you installed it |
| **Addons** | On its own. See [Managing Addons](/docs/user/managing-addons#updates) |

## Unbound

Each launch, Unbound downloads a newer version if there is one. If the check fails, it keeps the version it has. On Android a dialog may say so; tap **Okay**.

To update now, open the [toolbox](/docs/user/troubleshooting#toolbox) and tap **Refetch Bundle**. Discord restarts on the newest version.

## The App

When a new app version is out, **Updates** on the **Unbound** page lists **Unbound loader** with a **Download** button.

| Installed with | Update by |
| --- | --- |
| iOS sideloading source | Refresh the source in your tool, then install the update |
| iOS app file | Install the latest [Unbound.ipa](https://github.com/marioparaschiv/unbound/releases/download/loader-latest/Unbound.ipa) with your tool |
| iOS jailbreak | Refresh sources, update the **Unbound** package, then reopen Discord |
| Android, Obtainium | Tap **Update**. For the Xposed module, then force stop and reopen Discord |
| Android, by hand | Install the newer file from [GitHub releases](https://github.com/marioparaschiv/unbound/releases) over the old one. Use your split-APK installer for the patched Discord |

On a jailbreak, **This version of Discord is incompatible with this version of Unbound.** means Discord is too old or too new. Update Discord from the App Store.

## Older Versions

iOS only.

<Steps>
	<Step title='Open the toolbox'>
		Shake your device for half a second to two seconds, or hold three fingers on the screen.
	</Step>
	<Step title='Tap Switch Bundle Version'>
		In **Bundle**. Needs internet.
	</Step>
	<Step title='Pick a version'>
		Pick a branch if asked, then one of its last 10 builds, such as `a1b2c3d (Mar 4, 2026)`. Discord restarts on it.
	</Step>
</Steps>

<Warning>
	The picked version stays pinned, and Unbound stops updating itself. To unpin, tap **Delete Bundle** in the toolbox and confirm. Addons and settings stay.
</Warning>
