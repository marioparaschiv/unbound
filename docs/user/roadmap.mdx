The Unbound client is complete: no new features are planned, and updates keep it working with Discord. Everything below works on iOS and Android unless noted.

## Available Now

| Area | What works |
| --- | --- |
| [Addons](/docs/user/marketplace) | Marketplace for plugins, themes and icon packs, with addon pages. Install older versions, from the website or a manifest URL. Libraries install with their plugin and stay hidden. Sort by popularity or newest, or show only what isn't installed. A third-party plugin shows what it can do before you install it. Over 200 official plugins such as Chat Bubbles, Message Logger, Translate and Voice Transcripts, ports of Vencord and Equicord plugins, and over 70 community themes |
| [Updates](/docs/user/updating) | Unbound updates in the background for the next launch, downloading only what changed. Addons update at startup or in the background, or by hand with changelogs. An addon update that crashes rolls back, and versions the store withdraws turn off. Update the client from **Updates**. Sideloaded installs update through their sideloader |
| [Customization](/docs/user/fonts) | Themes that reach native screens, a Theme Editor with live preview, icon packs, font packs, fonts including WOFF2 and variable fonts, configurable toasts, Discord's staff settings, and slash commands such as `/reload`, `/recovery` and `/debug`. Unbound speaks every language Discord does |
| [Account and Sync](/docs/user/sync) | Discord sign-in. Two-way, download-only or upload-only sync, with a merge choice for new devices, so addons and settings return after a reinstall. Delete cloud data. The Sync page shows what the cloud holds and uploads or downloads by hand. Sponsor badge for $5 a month or $30 once, and a sponsor role while sponsoring |
| [Recovery](/docs/user/troubleshooting) | Toolbox by shake or three fingers. Recovery Mode, also from the app icon shortcut. Auto-disable for plugins that crash two launches in a row or freeze, turned back on after they update. The Toolbox opens when Discord never draws. A recovery screen when a screen fails to draw, naming the plugin behind it. **Find a Problem Plugin** turns plugins off in halves. **Recent Crashes** lists crashes and the GitHub issue tracking each. The Toolbox offers the previous Unbound version. **Report Bug**, with a diagnostics zip from `/debug`. A warning when Discord is older than supported, before a Discord update breaks Unbound on Android, and before a sideloaded signing profile expires |
| [Privacy](/docs/user/privacy) | Discord analytics, Sentry and other tracking blocked. Crash reports opt-in, never with your account. Plugins ask before calling native code, list the hosts they reach, and get your account token only when they ask. Unbound updates are signature-checked |
| [iOS Extensions](/docs/user/ios-extensions) | Open Discord links from Safari, share files, text and links to Discord, passkey login through Safari, animated Unbound app icon (sideloaded) |

Unbound also builds on Discord's test versions: TestFlight on iOS, Google Play beta and alpha on Android.

## Developer Tools

- `ubd` [CLI](/docs/developer/tools/cli): create an addon, rebuild and reload on device while editing, submit for review.
- Components refresh in place without a restart.
- A `ubd` push is tagged **Dev copy**, skips update checks, and reinstalls from the Marketplace in one tap.
- The CLI runs code, reads logs and inspects native views. It also sends test messages, runs slash commands and background jobs, and copies files in and out of Discord. Its MCP server gives AI clients the same.
- [Debugger](/docs/developer/tools/debugger): terminal REPL inside Discord. Unbound DevTools: desktop app for macOS, Windows and Linux with React DevTools, a TypeScript console, live device logs, a Metro module browser, a native view tree, a class explorer and the `ubd` commands.
- Plugins can run background jobs, react to low memory, show Live Activities on iOS, and build Objective-C blocks and classes.
- Unbound turns off patches that keep throwing or loop, and names slow or crashing plugins in `/debug` and crash reports.
- **Developer Mode** adds the debugger, React DevTools, the Asset Browser and a custom bundle URL.
- Guides for plugins, themes and icon packs, plus an SDK reference per package version.
