## Available Now

| Area | What works |
| --- | --- |
| [Addons](/docs/user/marketplace) | Marketplace for plugins, themes and icon packs, with store pages. Install older versions, from the website or a manifest URL. Libraries install with their plugin and stay hidden. Official plugins such as Chat Bubbles, Avatar Radius, Message Logger and Translate |
| [Updates](/docs/user/updating) | Unbound updates in the background for the next launch. Addons update at startup, or by hand with changelogs. New app versions show on **Updates** |
| [Customization](/docs/user/fonts) | Themes that reach native screens, icon packs, fonts, configurable toasts, Discord's staff settings, and slash commands such as `/reload`, `/recovery` and `/debug` |
| [Account and Sync](/docs/user/sync) | Discord sign-in. Two-way, download-only or upload-only sync, with a merge choice for new devices. Delete cloud data. $5 a month sponsor badge and role |
| [Recovery](/docs/user/troubleshooting) | Toolbox by shake or three fingers. Recovery Mode, also from the app icon shortcut. Auto-disable for plugins that crash two launches in a row or freeze. A recovery screen when a screen fails to draw. **Report Bug**. A warning when Discord is older than supported |
| [Privacy](/docs/user/privacy) | Discord analytics blocked. Crash reports opt-in, never with your account. Plugins ask before calling native code. Unbound updates are signature-checked |
| [iOS Extensions](/docs/user/ios-extensions) | Open Discord links from Safari, share to Discord, passkey login through Safari, Unbound app icon (sideloaded) |

## Developer Tools

- `ubd` [CLI](/docs/developer/tools/cli): create an addon, rebuild and reload on device while editing, submit for review.
- Components refresh in place without a restart.
- A `ubd` push is tagged **Dev copy**, skips update checks, and reinstalls from the store in one tap.
- The CLI runs code, reads logs and inspects native views. Its MCP server gives AI clients the same.
- [Debugger](/docs/developer/tools/debugger): terminal REPL inside Discord. Unbound DevTools: desktop React DevTools for macOS, Windows and Linux.
- **Developer Mode** adds the debugger, React DevTools, the Asset Browser and a custom bundle URL.
- Guides for plugins, themes and icon packs, plus an SDK reference per package version.
