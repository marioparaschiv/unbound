The Unbound client is feature-complete. Updates now only keep it working with new Discord versions. Everything below works on iOS and Android unless noted.

## Available Now

| Area | What works |
| --- | --- |
| [Addons](/docs/user/marketplace) | Marketplace for plugins, themes and icon packs, with addon pages. Install older versions, from the website or a manifest URL. Libraries install with their plugin and stay hidden. Sort by popularity or newest, or hide what you already have. Third-party plugins show what they can access before you install them. Over 200 official plugins, including Chat Bubbles, Message Logger, Translate and Voice Transcripts, plus Vencord and Equicord ports and over 70 community themes |
| [Updates](/docs/user/updating) | Unbound downloads only what changed and applies it on the next launch. Addons update at startup, in the background, or by hand with changelogs. If an addon update crashes, Unbound rolls it back. Versions pulled from the store turn off. Update the client from **Updates**. Sideloaded installs update through their sideloader |
| [Customization](/docs/user/fonts) | Themes that reach native screens, a Theme Editor with live preview, icon packs, font packs, fonts including WOFF2 and variable fonts, configurable toasts, Discord's staff settings, and slash commands such as `/reload`, `/recovery` and `/debug`. Unbound speaks every language Discord does |
| [Account and Sync](/docs/user/sync) | Discord sign-in. Two-way, download-only or upload-only sync, with a merge choice for new devices, so addons and settings return after a reinstall. Delete cloud data. The Sync page shows what the cloud holds and uploads or downloads by hand. Sponsor badge for $5 a month or $30 once, and a sponsor role while sponsoring |
| [Recovery](/docs/user/troubleshooting) | Toolbox by shake or three fingers. Recovery Mode, also from the app icon shortcut. Auto-disable for plugins that crash two launches in a row or freeze, turned back on after they update. The Toolbox opens when Discord never draws. A recovery screen when a screen fails to draw, naming the plugin behind it. **Find a Problem Plugin** turns off half your plugins at a time until it finds the bad one. **Recent Crashes** links each crash to its GitHub issue. The Toolbox can go back to the previous Unbound version. **Report Bug** attaches a diagnostics zip from `/debug`. Unbound warns you when Discord is older than supported, before a Discord update breaks it on Android, and before a sideloaded signing profile expires |
| [Privacy](/docs/user/privacy) | Unbound blocks Discord analytics, Sentry and other tracking. Crash reports are opt-in and never include your account. Plugins ask before calling native code, list the servers they contact, and only get your account token if they request it. Unbound updates are signature-checked |
| [iOS Extensions](/docs/user/ios-extensions) | Open Discord links from Safari, share files, text and links into Discord, sign in with a passkey through Safari, and use the animated Unbound app icon (sideloaded) |

See [Installation](/docs/user/installing).

| Method | Platform |
| --- | --- |
| Jailbreak tweak from the apt repo | iOS |
| Sideloaded app from SideStore, AltStore, Feather or the IPA | iOS |
| Xposed module with Vector, rooted | Android |
| Pre-patched Discord, no root | Android |

Unbound also builds on Discord's test versions: TestFlight on iOS, Google Play beta and alpha on Android.

## Developer Tools

- `ubd` [CLI](/docs/developer/tools/cli): create an addon, rebuild and reload on device while editing, submit for review.
- Components refresh in place without a restart.
- A `ubd` push is tagged **Dev copy**, skips update checks, and reinstalls from the Marketplace in one tap.
- The CLI runs code, reads logs and inspects native views. It can also send test messages, run slash commands and background jobs, and copy files in and out of Discord. Its MCP server gives AI clients the same tools.
- [Debugger](/docs/developer/tools/debugger): terminal REPL inside Discord. Unbound DevTools: desktop app for macOS, Windows and Linux with React DevTools, a TypeScript console, live device logs, a Metro module browser, a native view tree, a class explorer and the `ubd` commands.
- Plugins can run background jobs, react to low memory, show Live Activities on iOS, and build Objective-C blocks and classes.
- Unbound turns off patches that keep throwing or loop forever. `/debug` and crash reports name slow or crashing plugins.
- **Developer Mode** adds the debugger, React DevTools, the Asset Browser and a custom bundle URL.
- Guides for plugins, themes and icon packs, plus an SDK reference per package version.

## Website

- Browse addons by tag, author, popularity and update date, and install to your device.
- Addon pages with versions and changelogs.
- Sign in with Discord.
- Developer profiles with addons and badges.
- Design and preview your sponsor badge.
- Submit from GitHub, preview the addon page and follow review.
- Dashboard for addons and submissions, with maintainers.
- Approve a device so `ubd auth login` can publish.
- Crash reports become GitHub issues, with short links and a count of affected devices.
