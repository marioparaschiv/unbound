## Addons

You get addons from the **Marketplace** in Unbound's settings. See [Finding Addons](/docs/user/marketplace) and [Managing Addons](/docs/user/managing-addons).

- Browse and install plugins, themes, and icon packs from the Marketplace.
- Read an addon's store page before you install it.
- Install an older version of an addon. Unbound keeps it on that version and pauses its updates.
- Install an addon from a link on the Unbound website, or from the URL of its manifest.
- Install the libraries a plugin needs together with the plugin. Libraries stay hidden in your plugin list.
- Turn addons on and off, change a plugin's settings, and delete addons.
- Use official plugins from the Unbound team, such as Chat Bubbles, Avatar Radius, Message Logger, and Translate.

## Updates

See [Updating](/docs/user/updating).

- Unbound downloads its own updates in the background and uses them from the next launch.
- The **Updates** page checks your addons for new versions. Tap an update to read what changed, then update one addon or all of them.
- Addon updates install each time Discord starts. Turn off **Update automatically** to install them yourself.
- The **Updates** page also tells you when a new version of the Unbound app is out, with a link to download it.

## Customization

- Apply a theme. Its colors reach Discord's native screens too.
- Replace Discord's icons with an icon pack.
- Change Discord's fonts to fonts on your device or font files you add. See [Fonts](/docs/user/fonts).
- Unbound shows its own toasts in place of Discord's. You choose their duration, opacity, blur, animations, and how many show at once.
- Show the settings Discord keeps for its staff.
- Use Unbound's slash commands, such as `/reload`, `/recovery`, and `/debug`.

## Account and sync

See [Account and Sync](/docs/user/sync).

- Sign in to Unbound with your Discord account.
- Sync your addons and settings across your devices. Choose two-way, download only, or upload only.
- Choose how a new device combines with the setup already in your cloud. You can merge both, use the cloud's setup, or use the device's setup.
- Delete your synced data from Unbound's servers.
- Sponsor Unbound on GitHub for $5 a month to get a custom badge and a Sponsor role in the Unbound Discord server.

## Recovery and reliability

See [Troubleshooting](/docs/user/troubleshooting).

- The **toolbox** is a recovery menu that opens even when Unbound fails to load. Shake your device or hold three fingers on the screen to open it.
- **Recovery Mode** starts Discord with every addon off.
- Start Recovery Mode from the shortcut menu of Discord's app icon.
- Unbound turns off an addon that crashes Discord on two launches in a row.
- Unbound turns off a plugin that freezes Discord twice in one session, or once for a long time.
- When a screen fails to draw, Unbound shows a recovery screen instead of crashing.
- **Report Bug** opens a GitHub issue with your debug info already filled in.
- Unbound warns you when your Discord version is older than the oldest one it supports.

## Privacy and security

See [Privacy](/docs/user/privacy).

- Unbound blocks Discord's analytics tracking.
- Crash reports stay off until you turn them on. A report never includes your account.
- A plugin must ask you before it can call native code directly.
- Unbound checks the signature of each Unbound update before it runs it.

## Install options

See [Installing](/docs/user/installing).

| How you install | Platform |
| --- | --- |
| Tweak on a jailbroken device, from the apt repo | iOS |
| Sideloaded app, from SideStore, AltStore, Feather, or the IPA file | iOS |
| Xposed module with Vector on a rooted device | Android |
| Pre-patched Discord, no root needed | Android |
| Automatic app updates through Obtainium | Android |

Unbound also builds for Discord's test versions. That means TestFlight on iOS, and the beta and alpha channels of Google Play on Android.

## iOS extras

See [iOS Extensions](/docs/user/ios-extensions).

- Open Discord links from Safari in the Discord app.
- Share photos, videos, and files from other apps to a Discord channel or DM.
- Log in with a passkey through Safari in a sideloaded app.
- Switch Discord's app icon to the Unbound logo in a sideloaded app.

## For developers

- The `ubd` CLI creates an addon, rebuilds and reloads it on your device while you edit, and submits it for review. See [CLI](/docs/developer/development/cli).
- Edited components refresh in place on the device, without a restart.
- A copy you pushed with `ubd` is tagged **Dev copy**, stays out of update checks, and reinstalls from the store in one tap.
- The CLI also runs code, reads logs, and inspects native views on a connected device. Its MCP server lets AI clients do the same.
- The debugger is a terminal REPL that runs JavaScript inside Discord. See [Debugging](/docs/developer/development/debugging).
- Unbound DevTools is a desktop React DevTools app for macOS, Windows, and Linux.
- **Developer Mode** adds a **Developer** page with the debugger, React DevTools, the Asset Browser, and a custom bundle URL.
- The docs include guides for plugins, themes, and icon packs, and an API reference for each package version.

## Website

- Browse plugins, themes, and icon packs, filter them by tag, author and update date, and install one on your device from its page.
- Read an addon's store page, its versions and their changelogs.
- Sign in with Discord.
- Open a developer's profile to see their addons and badges.
- Design your sponsor badge and preview it as a Discord profile badge.
- Submit an addon from a GitHub repository, preview its store page, and follow its review.
- Track your addons and submissions on your dashboard, and add maintainers to an addon.
- Approve a device so `ubd login` can publish for you.
