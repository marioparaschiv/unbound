Your installed addons live in the **Unbound** section of Discord's settings. Plugins are on the **Plugins** page. Themes and icon packs are on the **Design** page, under the **Themes** and **Icons** tabs. To install one, see [Finding Addons](/docs/user/marketplace).

## An addon's card

Each addon is a card with its name, authors, description and version. The controls sit in its top right corner:

| Control | What it does |
| --- | --- |
| Gear | Opens the plugin's settings. Grayed out when the plugin has none, or is turned off |
| **⋯** | Opens a menu with **Delete** |
| Switch | Turns a plugin on or off |
| Check mark | Applies a theme or icon pack |

## Plugins

Tap a plugin's switch to turn it on or off. It takes effect right away, with no restart. You can run as many plugins as you like.

## Themes

Only one theme is applied at a time.

<Steps>
	<Step title='Open Design, then Themes'>
		Each theme is a card.
	</Step>
	<Step title='Tap the theme you want'>
		A check mark appears on it, and the theme you had before is unselected.
	</Step>
	<Step title='Tap Restart'>
		Unbound asks to restart, so the theme applies everywhere.
	</Step>
</Steps>

To go back to Discord's own colors, tap the applied theme again to unselect it, then restart.

## Icon packs

Open **Design**, then **Icons**, and tap the pack you want. It applies right away. Any icon the pack doesn't include keeps Discord's look. To go back to Discord's icons, tap the applied pack again to unselect it.

## Updates

Unbound checks your addons for updates and installs them when Discord starts. To see what's new first, or to update by hand:

<Steps>
	<Step title='Open Updates'>
		On the **Unbound** page, tap **Updates** at the top.
	</Step>
	<Step title='Read what changed'>
		Each available update is listed. Tap one to read its changelog.
	</Step>
	<Step title='Update'>
		Tap **Update** on one, or **Update all**.
	</Step>
</Steps>

Turn off **Update automatically** on that page to only update by hand. An addon you held at an older version with **Choose version** sits out automatic updates. See [Install an older version](/docs/user/marketplace#install-an-older-version).

## Removing an addon

Tap **⋯** on its card, then **Delete**, and confirm. Its files are removed from your device.

- A removed plugin stops right away.
- A removed icon pack brings back Discord's icons.
- A removed theme's colors stay until you restart.

If you delete a library that other plugins need, Unbound names them. You can delete just the library, or the library and the plugins that need it.

## When an addon breaks

An addon that fails to start is dimmed, with its error in red under it. You can still delete it from **⋯**.

Unbound also turns a plugin off on its own when it crashes Discord on two launches in a row, or freezes it for too long. If a plugin keeps Discord from opening at all, see [Troubleshooting](/docs/user/troubleshooting#an-addon-breaks-discord).
