Plugins live on the **Plugins** page. Themes and icon packs live on **Design**, under **Themes** and **Icons**. To get more, see [Finding Addons](/docs/user/marketplace).

## Card Controls

| Control | Does |
| --- | --- |
| Gear | Opens a plugin's settings. Grayed out when it has none or is off |
| **⋯** | Menu with **Delete** |
| Switch | Turns a plugin on or off |
| Check mark | Applies a theme or icon pack |

## Applying

| Kind | How | Takes effect |
| --- | --- | --- |
| Plugin | Tap its switch. Run as many as you like | Right away |
| Theme | Tap it, then **Restart**. One at a time | After restart |
| Icon pack | Tap it. One at a time | Right away |

Tap an applied theme or icon pack again to go back to Discord's look. A theme needs a restart for that too. Icons a pack lacks keep Discord's look.

## Updates

Addons update when Discord starts. To review first or update by hand:

<Steps>
	<Step title='Open Updates'>
		At the top of the **Unbound** page.
	</Step>
	<Step title='Read the changelog'>
		Tap an update.
	</Step>
	<Step title='Update'>
		Tap **Update** on one, or **Update all**.
	</Step>
</Steps>

Turn off **Update automatically** there to only update by hand. An addon pinned with [Choose version](/docs/user/marketplace#older-versions) skips automatic updates.

## Removing

Tap **⋯**, then **Delete**, and confirm. Its files leave your device.

| Kind | After delete |
| --- | --- |
| Plugin | Stops right away |
| Icon pack | Discord's icons return |
| Theme | Colors stay until restart |

Deleting a library that other plugins need lists them. Delete the library alone, or with those plugins.

## Broken Addons

An addon that fails to start is dimmed, with its error in red. You can still delete it.

Unbound turns a plugin off when it crashes Discord on two launches in a row, or freezes it too long. If Discord won't open, see [Troubleshooting](/docs/user/troubleshooting#broken-addons).
