The **Marketplace** lists every published addon, each reviewed first. Open it from the **Unbound** section of Discord's settings.

## Installing

<Steps>
	<Step title='Pick a tab'>
		**Plugins**, **Themes** or **Icons**. Swipe between them, or search by name.
	</Step>
	<Step title='Open a card'>
		Its addon page shows screenshots and what it does.
	</Step>
	<Step title='Tap Install'>
		Plugins install turned off, and themes and icon packs unapplied. See [Managing Addons](/docs/user/managing-addons).
	</Step>
</Steps>

An installed addon with a newer version shows **Update** instead.

## Libraries

Some plugins need another plugin, a **library**. Installing one lists what it needs and offers **Install all**. On **Plugins**, libraries fold away under a button such as **+1 library**.

## Older Versions

Press and hold **Install** or **Update**, tap **Choose version** if asked, and pick a version.

<Note>
	A picked version stays put. That addon's automatic updates pause until you tap **Update** on it.
</Note>

## From the Website

Each addon on [unbound.rip](https://unbound.rip/addons) has an **Install** button. On a phone it opens the addon in Discord's Marketplace. On a computer it copies an install link.

## From a Link

An addon outside the Marketplace installs from a link to its manifest. Only use links from authors you trust.

<Steps>
	<Step title='Open its page'>
		**Plugins** for a plugin. **Design**, then its tab, for a theme or icon pack.
	</Step>
	<Step title='Tap +'>
		Bottom right, then **Install from URL**.
	</Step>
	<Step title='Paste and install'>
		The addon appears as a new card.
	</Step>
</Steps>

<Warning>
	Use the page that matches the addon. A theme link on **Plugins** doesn't install.
</Warning>
