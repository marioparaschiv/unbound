Sign in with Discord to turn on Sync and get [sponsor perks](#sponsor-perks). Sync stores install links and settings, never addon files.

## Turning On Sync

<Steps>
	<Step title='Sign in'>
		On the **Unbound** page, tap **Sign in with Discord** and approve.
	</Step>
	<Step title='Open Sync'>
		Under **Preferences**.
	</Step>
	<Step title='Choose how to combine'>
		Asked only if another device synced already. Nothing syncs until you pick.
	</Step>
</Steps>

| Choice | Result |
| --- | --- |
| **Merge both** | Addons from both. The cloud's settings win conflicts |
| **Use the cloud's setup** | Replaces this device's addons and settings |
| **Use this device's setup** | Replaces the cloud's |

**Sync automatically** is then on. **Sync now** syncs right away. The line below shows the last sync, or why it failed.

## Direction

| Direction | Result |
| --- | --- |
| **Two-way** | Changes on any device reach all |
| **Download only** | This device mirrors the cloud |
| **Upload only** | The cloud mirrors this device |

## Leaving

| Action | Result |
| --- | --- |
| **Sign out** | Stops syncing here. Nothing changes locally |
| **Delete cloud data** | Deletes your synced data from Unbound's servers and turns Sync off here. Nothing installed is removed |
