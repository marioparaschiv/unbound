Unbound is a mod for the Discord app on iPhone, iPad and Android. It adds **addons** to Discord: new features, colors, icons and fonts.

## Concepts

| Term | What it means |
| --- | --- |
| **Plugin** | Adds a feature or changes how Discord works. Run as many as you like |
| **Theme** | Recolors Discord. One at a time, applies after a restart |
| **Icon pack** | Replaces Discord's icons. One at a time |
| **Font** | Changes one kind of text, such as messages |
| **Marketplace** | Where you browse and install addons |
| **Recovery Mode** | Starts Discord with every addon off, to fix a crash |
| **Toolbox** | A recovery menu you open by shaking your phone. Works even when Unbound fails to load |
| **Sync** | Keeps your addons and settings the same on every device |

## Where It Lives

Open Discord's settings. Unbound adds its own section at the top.

| Page | What's there |
| --- | --- |
| **Unbound** | Recovery Mode, updates, your account and options. See [Settings](/docs/user/settings) |
| **Plugins** | Your plugins |
| **Design** | Your themes, icon packs and fonts |
| **Marketplace** | Every published addon. See [Finding Addons](/docs/user/marketplace) |
