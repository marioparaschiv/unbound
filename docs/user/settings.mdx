The **Unbound** page tops the **Unbound** section of Discord's settings. Tap the version at the top to read its changes on GitHub.

## Quick Actions

| Button | Does |
| --- | --- |
| **Restart** | Restarts Discord, after asking |
| **Updates** | Checks addons and Unbound. See [Managing Addons](/docs/user/managing-addons#updates) |
| **Report Bug** | Opens a GitHub issue with your versions and device filled in |

## Options

| Option | Default | Does |
| --- | --- | --- |
| **Recovery Mode** | Off | Stops every addon from loading. Asks to restart. See [Troubleshooting](/docs/user/troubleshooting) |
| **Account** | | Sign in with Discord for [Sync](/docs/user/sync) and [sponsor perks](/docs/user/sync#sponsor-perks) |
| **Toasts** | | Opens [toast settings](#toasts) |
| **Sync** | | See [Account and Sync](/docs/user/sync) |
| **Developer Mode** | Off | Adds the **Developer** page and logs more. See [Debugger](/docs/developer/tools/debugger) |
| **Discord Staff Settings** | Off | Shows Discord's own staff settings |
| **Send Crash Reports** | Off | Reports plugin crashes, freezes and failed starts. Asks first. See [Privacy](/docs/user/privacy#what-unbound-sends) |

**Help** links to the Support Server, these docs and Unbound's GitHub.

## Toasts

Under **Preferences**. A preview shows each change, and **Send a test toast** shows a real one.

| Option | Default | Does |
| --- | --- | --- |
| **Enable Toasts** | On | Replaces Discord's toasts. Off hides toasts from Unbound and plugins |
| **Animations** | On | Slides toasts in and out |
| **Opacity** | 80% | Below 100%, **Blur** shows |
| **Blur** | 15% | Blurs what's behind a toast |
| **Max Toasts on Screen** | 3 | Up to 10, or **Unlimited** |
| **Duration** | 5s | Up to 10 seconds, or **Indefinite**. A toast with its own length ignores it |
