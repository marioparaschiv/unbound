Unbound blocks part of Discord's tracking. Discord still sees your account, messages and connection.

## What Unbound Blocks

| Tracking | Blocked on |
| --- | --- |
| Usage analytics: screens you open, buttons you tap | iOS and Android |
| Connection analytics: app connects and disconnects | iOS and Android |
| Discord's analytics fingerprint for your device | iOS and Android |
| **Sentry** crash and error reports | iOS and Android |
| **Firebase Installations** per-install id | iOS |
| **AppsFlyer** install attribution | Android |

Blocking is always on, Recovery Mode included, with no setting. If a Discord update moves one of these, it goes unblocked and Unbound only logs it.

## What Discord Sees

Your account, messages, the servers and channels you open, your IP address, and the device and app details sent with normal requests.

## What Unbound Sends

Unbound has no analytics. Downloads never carry your Discord account. Every server sees your IP address.

| When | Where | What |
| --- | --- | --- |
| Every launch | `builds.unbound.rip` | Update check |
| Every launch | GitHub | Translations for English and your Discord language, such as `de` |
| Marketplace or addon updates | `unbound.rip`, `cdn.unbound.rip` | Addon list, then addons you install |
| Install from a link | The link's host | The addon's files |
| Signed in | `unbound.rip` | Sign-in, synced install links and settings. See [Account and Sync](/docs/user/sync) |
| **Send Crash Reports** on | `unbound.rip` | See [Crash Reports](#crash-reports) |
| **Switch Bundle Version** (iOS) | GitHub | Build list |
| **Load Custom Bundle** (iOS) | The address you enter | The bundle |

## Crash Reports

Off until you turn them on. When a plugin crashes, freezes or fails to start, a report holds:

- The plugin's id, version and whether it's signed.
- The freeze length, or the error for a failed start.
- Unbound, loader and Discord versions.
- Your platform, OS version and device model.

It never holds your Discord account, messages or plugin settings.
