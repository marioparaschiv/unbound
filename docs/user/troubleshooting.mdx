Start with the problem you have. Most fixes take a minute, and none of them need you to reinstall.

## Discord crashes or won't open

The **toolbox** is a recovery menu built into the app. It opens even when the rest of Unbound fails to load. Work through these fixes in order, and stop once Discord works again.

<Steps>
	<Step title='Open the toolbox'>
		See [Open the toolbox](#open-the-toolbox) below.
	</Step>
	<Step title='Tap Refetch Bundle'>
		It downloads Unbound again if a newer version is out, and restarts.
	</Step>
	<Step title='Tap Enable Recovery Mode'>
		Discord restarts with every addon turned off. If it opens now, an addon is the cause. See [An addon breaks Discord](#an-addon-breaks-discord).
	</Step>
	<Step title='Tap Delete Bundle'>
		It deletes Unbound's downloaded copy, undoes any version you pinned, and downloads the latest one on the next launch. Your addons and settings stay.
	</Step>
</Steps>

If none of these help, [report a bug](#report-a-bug).

## Open the toolbox

Use either gesture. Both are on by default.

- **Shake your device** for half a second to two seconds, then stop. Shorter shakes do nothing, and longer ones are ignored, so a bumpy ride doesn't open it.
- **Hold three fingers** anywhere on the screen for half a second.

On Android you can also press and hold Discord's app icon and pick the recovery shortcut. It turns Recovery Mode on or off, even when Discord crashes before you can shake it.

<Note>
	You can turn off either gesture in the toolbox's **Settings**, but not both. Turning one off turns the other back on, so you can't lock yourself out.
</Note>

## An addon breaks Discord

Unbound turns a plugin off on its own when it:

- crashes Discord on two launches in a row, or
- freezes Discord for 6 seconds or more, twice in one session, or once for 20 seconds.

Turn it back on from the **Plugins** page once the plugin has an update. To find and remove the addon yourself:

<Steps>
	<Step title='Turn on Recovery Mode'>
		On the **Unbound** page if Discord opens, or from the toolbox if it doesn't. Restart when asked, and Discord opens with every addon off.
	</Step>
	<Step title='Delete the addon'>
		Tap **⋯** on its card, then **Delete**. In Recovery Mode you can't turn addons on or off, but you can delete them.
	</Step>
	<Step title='Turn off Recovery Mode'>
		Then restart Discord.
	</Step>
</Steps>

If Unbound itself won't run, Recovery Mode can't help. Use the toolbox's **Addons** section, which deletes every addon of one kind at once:

| Action | Deletes |
| --- | --- |
| **Wipe Plugins** | Every plugin |
| **Wipe Themes** | Every theme |
| **Wipe Fonts** | Every font file you added |
| **Wipe Icon Packs** | Every icon pack |
| **Factory Reset**, in **Utilities** | Everything: addons, settings and Unbound's downloaded copy |

<Warning>
	These can't be undone, and nothing is backed up. To remove a single addon on iOS instead, tap **Open App Folder** in **Utilities**, and delete the addon's folder from **Plugins**, **Themes** or **Icons**. Then restart Discord.
</Warning>

## Android shows an Unbound error dialog

The dialog is titled **Unbound**, with an **Okay** button and a **Discord Server** button that opens Unbound's support server.

| Message | What it means |
| --- | --- |
| `Bundle failed to download, please report this to the developers.` | Unbound has nothing to load yet, and the download failed. Discord opens without Unbound |
| `Bundle failed to update, loading out of date bundle.` | The download failed, so Unbound loads the older copy it has |
| `Bundle not found, please report this to the developers.` | Unbound has nothing to load after the update step. Discord opens without Unbound |
| `Failed to load Unbound's bundle. Please report this to the developers.` | Unbound's copy hit an error while starting |
| `[Updater] Failed to check for updates, bundle may be out of date. Please report this to the developers.` | The update check failed. Unbound keeps the copy it has |

Without internet, the first two appear on their own. Connect and open Discord again.

## Obtainium doesn't find or install Unbound

- **No releases found, or the wrong channel.** Check the source's options against the table in [Installing](/docs/user/installing#android-patched), under **The links don't open Obtainium**.
- **The install or update fails.** The patched Discord is signed differently from the Play Store one. Uninstall Discord, then install from Obtainium again.
- **Going back from alpha or beta to stable fails.** The installed Discord is newer than the stable build. Uninstall Discord, then install from the stable source.

## Report a bug

If Discord opens, tap **Report Bug** at the top of the **Unbound** page. It opens a new GitHub issue that already lists your Unbound and Discord versions and your device. Describe what happened and how to make it happen again.

If Discord won't open, tap **Open GitHub Issue** in the toolbox's **Utilities** section instead.

<AccordionGroup>
	<Accordion title='Attach logs from iOS' icon='apple'>
		You need a Mac. Connect your device, open Console.app, select the device, and press **Start streaming**. Filter on the subsystem `app.unbound`, make the problem happen, then copy the messages into the issue.
	</Accordion>
	<Accordion title='Attach logs from Android' icon='mobile'>
		Turn on USB debugging and connect the device to a computer. Run `adb logcat -s Unbound`, force stop Discord, open it again, and make the problem happen. Then copy the messages into the issue.
	</Accordion>
</AccordionGroup>
