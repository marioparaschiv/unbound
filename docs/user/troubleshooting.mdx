## Discord Won't Open

Try these in order. Stop once Discord works.

<Steps>
	<Step title='Open the toolbox'>
		See [Toolbox](#toolbox).
	</Step>
	<Step title='Tap Refetch Bundle'>
		Downloads a newer Unbound if there is one, and restarts.
	</Step>
	<Step title='Tap Enable Recovery Mode'>
		Restarts with every addon off. If Discord opens, an addon is the cause. See [Broken Addons](#broken-addons).
	</Step>
	<Step title='Tap Delete Bundle'>
		Deletes Unbound's downloaded copy and any pinned version. The latest downloads on next launch. Addons and settings stay.
	</Step>
</Steps>

Still broken? [Report a bug](#reporting-a-bug).

## Toolbox

The toolbox opens even when Unbound fails to load. Both gestures are on by default.

| Gesture | How |
| --- | --- |
| Shake | Half a second to two seconds, then stop. Shorter or longer shakes are ignored |
| Three fingers | Hold anywhere on the screen for half a second |
| App icon (Android) | Press and hold Discord's icon, pick the recovery shortcut. Toggles Recovery Mode even if Discord crashes first |

<Note>
	The toolbox's **Settings** can turn off one gesture, never both.
</Note>

## Broken Addons

Unbound turns a plugin off when it:

- crashes Discord on two launches in a row, or
- freezes Discord for 6 seconds or more twice in one session, or once for 20 seconds.

Turn it back on from **Plugins** once it has an update. To remove an addon yourself:

<Steps>
	<Step title='Turn on Recovery Mode'>
		On the **Unbound** page, or in the toolbox if Discord won't open. Restart when asked.
	</Step>
	<Step title='Delete the addon'>
		Tap **⋯**, then **Delete**. Recovery Mode blocks toggling addons, not deleting.
	</Step>
	<Step title='Turn off Recovery Mode'>
		Then restart Discord.
	</Step>
</Steps>

If Unbound itself won't run, use the toolbox's **Addons** section:

| Action | Deletes |
| --- | --- |
| **Wipe Plugins** | Every plugin |
| **Wipe Themes** | Every theme |
| **Wipe Fonts** | Every font file you added |
| **Wipe Icon Packs** | Every icon pack |
| **Factory Reset**, in **Utilities** | Addons, settings and Unbound's downloaded copy |

<Warning>
	These can't be undone. To remove one addon on iOS, tap **Open App Folder** in **Utilities**, delete its folder from **Plugins**, **Themes** or **Icons**, and restart Discord.
</Warning>

## Android Errors

A dialog titled **Unbound** has **Okay** and **Discord Server** buttons.

| Message | Meaning |
| --- | --- |
| `Bundle failed to download, please report this to the developers.` | Nothing to load and the download failed. Discord opens without Unbound |
| `Bundle failed to update, loading out of date bundle.` | Download failed. Loads the older copy |
| `Bundle not found, please report this to the developers.` | Nothing to load after updating. Discord opens without Unbound |
| `Failed to load Unbound's bundle. Please report this to the developers.` | Unbound hit an error while starting |
| `[Updater] Failed to check for updates, bundle may be out of date. Please report this to the developers.` | Update check failed. Keeps the copy it has |

Offline, the first two are expected. Connect and reopen Discord.

## Obtainium Problems

| Problem | Fix |
| --- | --- |
| No releases, or wrong channel | Check the options in [Installation](/docs/user/installing#android-patched), under **Links Not Opening** |
| Install or update fails | The installed Discord has another signature. Uninstall it, then install again |
| Alpha or beta back to stable fails | Uninstall Discord, then install from the stable source |

## Reporting a Bug

Tap **Report Bug** on the **Unbound** page, or **Open GitHub Issue** in the toolbox's **Utilities** if Discord won't open. The issue lists your versions and device. Add what happened and how to repeat it.

<AccordionGroup>
	<Accordion title='iOS Logs' icon='apple'>
		Needs a Mac. Connect the device, open Console.app, select it, and press **Start streaming**. Filter on subsystem `app.unbound`, reproduce the problem, and copy the messages.
	</Accordion>
	<Accordion title='Android Logs' icon='mobile'>
		Enable USB debugging and connect to a computer. Run `adb logcat -s Unbound`, force stop and reopen Discord, reproduce the problem, and copy the messages.
	</Accordion>
</AccordionGroup>
