The **Fonts** tab has a row per kind of text, such as normal text and headings. Each row shows its font, or **Default**.

## Changing a Font

<Steps>
	<Step title='Open Design, then Fonts'>
		In the **Unbound** section of Discord's settings.
	</Step>
	<Step title='Tap a row, then a font'>
		Your own files list first. Search to narrow the list.
	</Step>
	<Step title='Relaunch Discord'>
		Close it from the app switcher, then open it.
	</Step>
</Steps>

<Warning>
	Fonts apply only on a cold start. The **Restart** button on the **Unbound** page doesn't apply them.
</Warning>

To undo, tap the row, then **Reset**, and relaunch. A font Discord can't find falls back to Discord's.

## Adding Font Files

Copy the file straight into Unbound's **Fonts** folder, not a subfolder, then relaunch Discord. Every row then lists it. To remove one, delete it and relaunch.

| Platform | Reach the folder |
| --- | --- |
| iOS | [Toolbox](/docs/user/troubleshooting#toolbox), then **Open App Folder** in **Utilities** |
| Android | Needs root. Toolbox, then **Copy App Folder Path**, then a root file manager |
