Unbound runs inside the Discord app, so you install a version of Discord with Unbound built in.

<InstallQuiz>
	<InstallResult id='ios-source' title='Install from your sideloading tool'>
		<Steps>
			<Step title='Open your sideloading tool'>
				Open SideStore, Feather, AltStore, or the tool you use.
			</Step>
			<Step title='Add the Unbound source'>
				Add this source URL:

				```text
				https://repo.unbound.rip/app-repo.json
				```
			</Step>
			<Step title='Install Unbound'>
				Find **Unbound** in the source and install it. The source also lists **Unbound (TestFlight)**, built on Discord's TestFlight beta. Pick plain **Unbound** unless you want the beta.
			</Step>
			<Step title='Open the app'>
				Open the new app and log in to Discord.
			</Step>
		</Steps>

		<Note>
			If your tool offers to remove app extensions, keep them. Without them, Discord links from Safari don't open in the app, and sharing to Discord stops working. See [iOS Extensions](/docs/user/ios-extensions).
		</Note>
	</InstallResult>

	<InstallResult id='ios-ipa' title='Install the app file'>
		<Steps>
			<Step title='Download the app file'>
				Download [unbound.ipa](https://github.com/marioparaschiv/unbound/releases/download/loader-latest/unbound.ipa) from Unbound's GitHub releases.
			</Step>
			<Step title='Install it with your sideloading tool'>
				Open the file in your sideloading tool and install it.
			</Step>
			<Step title='Open the app'>
				Open the new app and log in to Discord.
			</Step>
		</Steps>

		<Note>
			If your tool offers to remove app extensions, keep them. Without them, Discord links from Safari don't open in the app, and sharing to Discord stops working. See [iOS Extensions](/docs/user/ios-extensions).
		</Note>

		<Warning>
			Install the ready-made **unbound.ipa**. Don't inject Unbound into a Discord app yourself. Unbound is built for the ElleKit tweak runtime, and other runtimes are likely to break features. Without ElleKit, the app shows a **Runtime Detection** alert.
		</Warning>
	</InstallResult>

	<InstallResult id='ios-no-tool' title='Get a sideloading tool first'>
		Apple only lets you install apps from the App Store. A sideloading tool installs apps from other places, such as Unbound. Set up one of these by following its own guide:

		- [SideStore](https://sidestore.io)
		- [Feather](https://github.com/khcrysalis/Feather)
		- [AltStore](https://altstore.io)

		Then come back, tap **Back**, and pick the tool you installed.
	</InstallResult>

	<InstallResult id='ios-jailbroken' title='Install from the Unbound repo'>
		<Steps>
			<Step title='Remove other Discord mods'>
				Unbound can't be installed alongside Enmity, Vendetta or Pyoncord. Remove them first if you have them.
			</Step>
			<Step title='Add the Unbound repo'>
				Open your package manager, such as Sileo, and add this repo:

				```text
				https://repo.unbound.rip
				```
			</Step>
			<Step title='Install Unbound'>
				Search for **Unbound** and install it. Your package manager also installs ElleKit if you don't have it yet.
			</Step>
			<Step title='Restart Discord'>
				Close Discord if it was running, then open it again.
			</Step>
		</Steps>

		To install without the repo, download the package from the [latest loader release](https://github.com/marioparaschiv/unbound/releases/tag/loader-latest), named like `app.unbound.ios_<version>_iphoneos-arm64.deb`, and open it in your package manager.

		If Discord shows **This version of Discord is incompatible with this version of the Tweak.**, your Discord app is too old or too new for this Unbound version, and Unbound won't load.
	</InstallResult>

Obtainium opens with the source filled in. Tap **Add**.

	<InstallResult id='android-rooted' title='Install the Xposed module'>
		On a rooted device, Unbound is an Xposed module that loads into the Discord you already have. You need:

		- Android 9 or newer.
		- An Xposed framework with libxposed API 101 or newer, such as Vector or LSPosed.
		- Discord (`com.discord`) from Google Play. Any channel works.

		<Steps>
			<Step title='Install the module'>
				[Add the Unbound module to Obtainium](obtainium://app/%7B%22id%22%3A%22app.unbound.android%22%2C%22url%22%3A%22https%3A%2F%2Fgithub.com%2Fmarioparaschiv%2Funbound%22%2C%22author%22%3A%22unbound-app%22%2C%22name%22%3A%22Unbound%20Loader%20%28Xposed%29%22%2C%22additionalSettings%22%3A%22%7B%5C%22apkFilterRegEx%5C%22%3A%5C%22%5Eapp%5C%5C%5C%5C.unbound%5C%5C%5C%5C.android%5C%5C%5C%5C.xposed%5C%5C%5C%5C.apk%24%5C%22%2C%5C%22filterReleaseTitlesByRegEx%5C%22%3A%5C%22%5EUnbound%20.%2B%20for%20Discord%20.%2B%2C%20Android%5C%22%2C%5C%22fallbackToOlderReleases%5C%22%3Atrue%2C%5C%22sortMethodChoice%5C%22%3A%5C%22date%5C%22%7D%22%7D) and install it. Or download `app.unbound.android.xposed.apk` from the [latest release](https://github.com/marioparaschiv/unbound/releases/tag/loader-latest) and install it like any other app.

				Open your Xposed manager and enable the **Unbound** module.

## After installing

Be online the first time you open Discord with Unbound. That's when it downloads Unbound's latest version. On later launches it checks for a newer version, and downloads it only when there is one.

### Check that Unbound is working

Open Discord's settings. A new **Unbound** section appears at the top of the list, with **General**, **Plugins**, **Design** and **Marketplace**. If it's missing, Unbound didn't load.

If the download fails and no earlier copy is saved on your device, Discord shows an alert and opens without Unbound. On iOS the alert reads **Failed to load Unbound's bundle. Please report this to the developers.**

### If you see a security warning

<Warning>
	Only install Unbound from the sources on this page. On iOS, if the app shows a **SECURITY WARNING** alert saying the injected tweak failed Unbound's integrity verification, you can't be sure your copy is free of malware. Uninstall it, and reinstall from one of the sources above.
</Warning>

### Open the recovery menu

Shake your device for half a second to two seconds, or hold three fingers on the screen for half a second. This menu, the toolbox, works even when the rest of Unbound fails to load. See [Troubleshooting](/docs/user/troubleshooting) for what it can do.
