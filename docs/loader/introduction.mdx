A loader is a native tweak or module that patches specific native functions to get JavaScript running inside Discord. It then uses that to load Unbound's JavaScript bundle, which provides Unbound's in-app features.

Discord is a React Native app, so there are several ways to get code to execute in it.

**Loaders are platform-specific, but the goal is the same experience on every platform.**
