Unbound is a mod for the Discord mobile app on iOS and Android. It lets you add plugins, themes, and icon packs to Discord.

- **Plugins** add features or change how parts of Discord behave.
- **Themes** change Discord's colors, and some add a background image.
- **Icon packs** replace Discord's icons with a different set.
