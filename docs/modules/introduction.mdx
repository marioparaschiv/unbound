The **Developer API** is the set of modules Unbound provides for building addons. They cover finding Discord's internals, persisting settings, localizing strings, showing toasts, and more.

Every module is published in the `@unbound-app/api` package. Import modules by name from the package root, or import each one from its own subpath. At runtime, the same modules are available on the `unbound` global.

```ts
import { metro, storage } from '@unbound-app/api';
// equivalent: import metro from '@unbound-app/api/metro';
// runtime global: unbound.metro
```

<Note>
	If you're new, start with [Metro](/modules/metro). Almost everything else, including assets, i18n, stores, and your own addons, uses it to locate Discord's modules.
</Note>
