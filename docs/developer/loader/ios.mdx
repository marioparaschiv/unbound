The iOS loader keeps every Unbound file in one `Unbound` folder in the app's Documents directory. In the Files app, open **On My iPhone → `<App Name>` → Unbound**.

## Storage

| Path | Contents |
| --- | --- |
| `Plugins/<id>` | A [plugin](/docs/developer/getting-started/lifecycle): `manifest.json` and its bundle. |
| `Themes/<id>` | A [theme](/docs/developer/themes/introduction): `manifest.json` and its bundle. |
| `Fonts` | Font files, directly in the folder. |
| `Icons/<id>` | An [icon pack](/docs/developer/icon-packs/introduction), laid out like Discord's asset tree. |
| `settings.json` | Every Unbound setting. See [Settings Reference](/docs/developer/loader/settings). |
| `unbound.bundle` or `unbound.js` | The injected bundle, depending on the source. Manage it from the toolbox. |

- To remove an addon, delete its folder.
- The loader rescans on each bundle load, so changes apply after a restart or reload.
- If `settings.json` is unreadable or invalid JSON, the loader copies it to `settings.json.corrupt-<timestamp>` and starts fresh. Look there if settings vanish.

## Toolbox Actions

| Action | Deletes |
| --- | --- |
| **Wipe Plugins**, **Wipe Themes**, **Wipe Fonts** | The matching folder. |
| **Wipe Icon Packs** | The `Icons` folder. |
| **Delete Bundle** | The bundle, and clears `loader.update.url` and `loader.update.force`. |
| **Factory Reset** | The whole `Unbound` folder, including `settings.json` and the bundle. |

For the toolbox, Recovery Mode and bug reports, see [Troubleshooting](/docs/user/troubleshooting).
