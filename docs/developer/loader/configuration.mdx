To configure the loader, add a `unbound` -> `loader` key to `settings.json` and set any of the properties below on it.

### Flags

<br />

<ResponseField name='enabled' type='boolean'>
  Controls whether the JavaScript bundle is injected into the app. Set it to `false` to disable Unbound completely until you turn it back on.
</ResponseField>
<ResponseField name='devtools' type='boolean'>
 	Enables developer tools such as React DevTools, which are useful when patching parts of the app's UI.
</ResponseField>
<ResponseField name='update' type='object'>
	Controls how the JavaScript bundle is updated. You can set your own bundle source and force the loader to always download the latest bundle.
	<Expandable title='object'>
		<ResponseField name='url' type='string'>
			The URL the bundle is fetched from. Override it to load a bundle from somewhere else.

			The usual reason is testing local changes to Unbound's bundle while contributing.
		</ResponseField>
		<ResponseField name='force' type='boolean'>
			Forces the loader to always fetch the latest bundle from `update.url`. If `update.url` is not set, the loader uses Unbound's official bundle URL.
		</ResponseField>
	</Expandable>
</ResponseField>

### Example
```json settings.json
{
	'unbound': {
		'loader': {
			'enabled': true,
			'devtools': true,
			'update': {
				'force': false,
				'url': 'https://localhost:8080/bundle.js'
			}
		}
	}
}
```
