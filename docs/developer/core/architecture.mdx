Unbound runs in four layers inside the stock Discord app. GitHub Actions build it and unbound.rip serves it.

## Layers

| Layer | Lives in | What it does |
| --- | --- | --- |
| Addons | Users' devices | Plugins, themes, icon packs and fonts, built against `@unbound-app/api`. See [Concepts](/docs/developer/concepts). |
| Unbound client | `packages/client` | Finds Discord's modules through Metro, patches them, and starts and stops addons. See [Metro](/docs/developer/plugins/metro). |
| Discord | The stock app | Its module registry, React Native UI, Flux stores and native views. It stays unmodified on disk. |
| Native loader | `packages/loader` | Runs Unbound's bundle before Discord's, updates it, guards against crashes, and backs the native bridge. See [The Loader](/docs/developer/loader/introduction). |

## At Launch

	<FlowStep title='Loader' detail="Reads settings.json, scans addon folders, runs the signed bundle before Discord's" />
	<FlowStep title='Client' detail='Traps Metro so every Discord module is searchable' />

	<FlowStep title='Addons' detail='Each manager starts its addons' />
	<FlowStep title='Discord' detail='Renders with every patch applied' />

If an addon crashes or freezes Discord, Unbound blames the addon whose code was running and disables it, so Discord keeps working.
