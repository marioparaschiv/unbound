An **addon** is something you install into Unbound to change Discord. There are three kinds. All three are built and managed the same way:

- Each ships a [manifest](/docs/developer/addons/manifest).
- Each follows the same [lifecycle](/docs/api/latest/plugins).
- Each is enabled, disabled, and persisted by the same code.

### The kinds

<CardGroup cols={3}>
	<Card title='Plugins' icon='plug' href='/docs/developer/plugins/introduction'>
		Code that runs. Adds features by finding and patching Discord's internals.
	</Card>
	<Card title='Themes' icon='paintbrush' href='/docs/developer/themes/introduction'>
		Data that restyles. A palette, plus an optional background, that Unbound applies to the UI.
	</Card>
	<Card title='Icon Packs' icon='icons' href='/docs/developer/icon-packs/introduction'>
		Image overrides. Replace Discord's built-in icons with your own.
	</Card>
</CardGroup>
