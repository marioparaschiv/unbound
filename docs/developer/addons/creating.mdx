This guide takes you from an empty folder to a plugin running on your phone. You need [Bun](https://bun.sh) on your computer, and a phone with [Unbound installed](/docs/user/installing) on the same network.

## Run the starter plugin

<Steps>
	<Step title='Scaffold a workspace'>
		`ubd`, Unbound's CLI, creates a workspace with one plugin in it. It asks for anything you leave out, such as your Discord user id.

		```bash
		bunx @unbound-app/cli create --kind plugin --name hello-world --shape repository --git-init --install
		cd hello-world
		```
	</Step>
	<Step title='Start the debugger bridge'>
		The bridge connects your computer to the phone. Leave it running in its own terminal.

		```bash
		bunx @unbound-app/debugger
		```

		It prints a `Devices` address, such as `192.168.1.20:9090`.
	</Step>
	<Step title='Connect your phone'>
		1. In Discord, open **Unbound** settings, then **General**, and turn on **Developer Mode**.
		2. Open the **Developer** screen and turn on **Enable Debugger**.
		3. Enter the `Devices` address in **Debugger Address**.
		4. Restart Discord.

		The bridge prints `Device connected`.
	</Step>
	<Step title='Send the plugin to your phone'>
		`push` builds the plugin, installs it, and starts it. The starter plugin greets you with a toast.

		```bash
		bunx @unbound-app/cli push hello-world
		```
	</Step>
	<Step title='Rebuild on every save'>
		`dev` watches your files. Each time you save, it rebuilds the plugin and reloads it on the phone.

		```bash
		bun run dev
		```
	</Step>
</Steps>

## What you got

The plugin lives in `plugins/hello-world`. Each feature gets its own folder under `src/`, and `src/index.tsx` only starts them.

<FileTree>
	<Folder name='hello-world'>
		<File name='manifest.json' note='Who the plugin is: its id, name and version' />
		<File name='ADDON.md' note='The page the store shows' />
		<Folder name='media' note='Images for the store page' />
		<Folder name='src'>
			<File name='index.tsx' note='Starts each feature' />
			<File name='settings.tsx' note='The settings panel' />
			<File name='constants.ts' note='Setting keys' />
			<Folder name='greeting' note='One feature: the greeting toast'>
				<File name='index.ts' />
				<File name='platform.ts' note='Picks the iOS or Android version' />
			</Folder>
		</Folder>
	</Folder>
</FileTree>

The entry file exports the plugin. Unbound calls `start` when the plugin is turned on, and shows `getSettingsPanel` in its settings.

```tsx src/index.tsx
import { startGreeting } from '~/greeting';
import Settings from '~/settings';

export default {
	start() {
		startGreeting();
	},

	getSettingsPanel: () => <Settings />,
};
```

## Make it change Discord

Add a feature that logs every message you send. Create a new folder for it.

```ts src/message-log/index.ts
import { metro, patcher } from '@unbound-app/api';

const Messages = metro.findByProps('sendMessage', 'receiveMessage');

export function startMessageLog() {
	patcher.before(Messages, 'sendMessage', ({ args }) => {
		logger.log('Sending a message to channel', args[0]);
	});
}
```

1. `findByProps` finds Discord's module that has both `sendMessage` and `receiveMessage`. The search waits until the patch first needs the module.
2. `patcher.before` runs your callback each time Discord sends a message, with the arguments Discord passed.
3. `logger` is a global every plugin gets. It prefixes each line with your plugin's name.

Then start the feature from the entry file:

```tsx src/index.tsx
import { startMessageLog } from '~/message-log';
import { startGreeting } from '~/greeting';
import Settings from '~/settings';

export default {
	start() {
		startGreeting();
		startMessageLog();
	},

	getSettingsPanel: () => <Settings />,
};
```

Save, and `dev` reloads the plugin. Send a message on your phone, and the log line appears in the bridge's terminal.

<Note>
	The plugin has no `stop`. Unbound records every patch a plugin makes, and removes them all when the plugin is turned off. [How Plugins Run](/docs/developer/plugins/introduction) explains what it cleans up for you.
</Note>
