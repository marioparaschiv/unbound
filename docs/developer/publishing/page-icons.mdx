Your [store page](/docs/developer/addons/store-page) can show icons from the [Nucleo Micro Bold](https://nucleoapp.com/) set, the same set the rest of the site uses. Write the icon's name between two colons, and the store draws the icon in its place, at text size and in the brand colour.

```md ADDON.md
## :sparkle: What it does

- :trash: Deleted messages stay in the chat, in red.
- :pen: Edited messages keep their earlier versions.

## :gear: Settings
```

## How shortcodes render

- A shortcode works in headings, paragraphs, and list items.
- Inside `code` spans and fenced code blocks, a shortcode stays text.
- A name that is not in the list below stays text, colons included. Check the spelling against the list.
- Put the icon at the start of a heading or list item. An icon in the middle of a sentence is harder to read.

<Note>
	The website draws page icons. The Unbound app shows the shortcode as text for now.
</Note>
