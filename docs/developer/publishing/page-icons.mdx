Write an icon name between colons in your [store page](/docs/developer/publishing/store-page), and the store draws a [Nucleo Micro Bold](https://nucleoapp.com/) icon at text size in the brand colour.

```md ADDON.md
## :sparkle: What it does

- :trash: Deleted messages stay in the chat, in red.
- :pen: Edited messages keep their earlier versions.

## :gear: Settings
```

## Rules

- Works in headings, paragraphs and list items.
- Stays text inside `code` spans and fenced code blocks.
- An unknown name stays text, colons included.
- Put the icon at the start of a heading or list item.

<Note>
	Only the website draws page icons. The Unbound app shows the shortcode as text for now.
</Note>
