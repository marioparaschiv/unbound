An icon pack replaces Discord's built-in icons with your own. Like a [theme](/docs/developer/themes/introduction), it's a restyling addon. A theme recolors the interface, and an icon pack replaces the *images* Discord renders for its icons.

## How icon packs work

Discord refers to each icon by name, such as `ic_message_delete`. For each name your pack has an image for, Unbound shows your image instead of Discord's. Names you leave out keep Discord's icon, so a pack can replace a few icons or all of them.

<Note>
	An icon pack overrides icons *by name*. The asset names that the [assets](/docs/api/latest/assets) module discovers are the same names a pack targets.
</Note>

## What an icon pack ships

Unlike a [plugin](/docs/developer/plugins/introduction), a pack ships no code. It's a folder of image files laid out like Discord's own assets.

## File layout

Each image sits at the same path as the Discord asset it replaces, without the leading `assets/`, and is named after the asset.

<FileTree>
	<Folder name='my-pack'>
		<File name='manifest.json' />
		<Folder name='images'>
			<File name='ic_message_delete.png' note='Scale 1' />
			<File name='ic_message_delete@2x.png' note='Scale 2' />
		</Folder>
	</Folder>
</FileTree>

Scale variants use the `@2x` and `@3x` suffixes. A file with no suffix is scale `1`. Unbound picks the **highest** scale present for each asset, so shipping only an `@3x` file is fine. An asset with no matching file in the pack keeps Discord's original.

## How installation resolves files

Unbound installs a pack from its manifest URL. The manifest's `source` field sets how the files are downloaded. For the in-app install steps, see [Managing Addons](/docs/user/managing-addons).

<AccordionGroup>
	<Accordion title='GitHub' icon='code-branch'>
		`main` is the repo URL. You can narrow it to a branch and folder with `/tree/<branch>/<subpath>`. Unbound reads the repo's file tree and downloads every file under that path into the pack folder. If `source` is omitted and `main` is a `github.com` URL, this method is used.
	</Accordion>
	<Accordion title='Other' icon='link'>
		The pack installs through the same bundle download path as other addons.
	</Accordion>
</AccordionGroup>

<Note>
	Only one pack applies at a time, like a [theme](/docs/developer/themes/introduction). Enabling a pack replaces the applied one. Disabling it brings back Discord's own icons.
</Note>

<Tip>
	Match Discord's icon names exactly. An override applies only when its name matches the asset Discord requests. A mismatched name does nothing.
</Tip>
