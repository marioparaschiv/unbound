An icon pack is a folder of images that replace Discord's icons by name. It ships no code.

## How It Works

- Discord requests each icon by name, such as `ic_message_delete`.
- If your pack has an image with that name, Unbound shows it instead.
- Names you leave out keep Discord's icon.
- One pack applies at a time. Enabling another replaces it; disabling restores Discord's icons.

The names a pack targets are the ones the [assets](/docs/sdk/latest/assets) module discovers.

## File Layout

Each image sits at the path of the Discord asset it replaces, without the leading `assets/`.

<FileTree>
	<Folder name='my-pack'>
		<File name='manifest.json' />
		<Folder name='images'>
			<File name='ic_message_delete.png' note='Scale 1' />
			<File name='ic_message_delete@2x.png' note='Scale 2' />
		</Folder>
	</Folder>
</FileTree>

| Suffix | Scale |
| --- | --- |
| none | `1` |
| `@2x` | `2` |
| `@3x` | `3` |

Unbound uses the highest scale present, so shipping only `@3x` works.

<Tip>
	Names must match Discord's exactly. A mismatched name does nothing.
</Tip>

## Install Sources

Unbound installs a pack from its manifest URL. The manifest's `source` sets how files download. For in-app steps, see [Managing Addons](/docs/user/managing-addons).

| `source` | Behavior |
| --- | --- |
| GitHub | `main` is the repo URL, optionally narrowed with `/tree/<branch>/<subpath>`. Unbound downloads every file under that path. Used by default when `source` is omitted and `main` is a `github.com` URL. |
| Other | Downloads like any other addon bundle. |

To install, enable or list packs from code, see [`iconPacks`](/docs/sdk/latest/iconPacks) in the SDK reference.
