A theme is a JSON palette, plus an optional background, that recolors Discord. It runs no code: for behavior, write a [plugin](/docs/developer/getting-started/lifecycle).

## How It Works

- A theme overrides Discord's named colors. Colors you leave out keep Discord's value.
- One theme applies at a time. Applying another replaces it.
- Colors apply when Discord starts, so a change shows after a restart.

## Make a Theme

The [theme maker](/themes/create) builds a theme from a base and three colors: background, accent and mentions.

- It previews the home, server, chat, profile and settings screens.
- **Advanced mode** sets single parts on top, such as the chat background, links or the @mention pill.
- It downloads a zip with `manifest.json` and `bundle.json`.

To edit by hand, unzip the folder into your workspace and edit `bundle.json`.

## Reload While Editing

With the [debugger](/docs/developer/tools/debugger) running and your phone connected, run from the workspace:

```bash
ubd dev
ubd push my-theme
```

| Command | Effect |
| --- | --- |
| `ubd dev` | Watches every addon and reloads the one you saved. |
| `ubd push <id>` | Sends one theme once, installing it if the device lacks it. |

To install, enable or list themes from code, see [`themes`](/docs/sdk/latest/themes) in the SDK reference.
