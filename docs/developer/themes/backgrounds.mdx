## Adding a background

To recommend an image behind the chat, add an optional `background` object to your theme definition. Set the image `url`, then adjust how it looks behind the messages with `blur` and `opacity`.

The background is a recommendation. Users see it by default, and they can swap in their own image or turn it off in **Design → Chat**.

```json bundle.json
{
	"type": "midnight",
	"background": {
		"url": "https://example.com/wallpaper.png",
		"blur": 4,
		"opacity": 0.5
	}
}
```

## Fields

<ResponseField name='url' type='string' required>
	The image to display behind the chat.
</ResponseField>
<ResponseField name='blur' type='number'>
	The blur radius in points, `0` when left out. Higher values soften the image so messages stay readable.
</ResponseField>
<ResponseField name='opacity' type='number'>
	How much of the image shows through the chat color, from `0` (hidden) to `1` (the image alone). Left out, it is `0.5`.
</ResponseField>

The chat color is your theme's `CHANNEL_BACKGROUND_DEFAULT`. While a background shows, Unbound draws it at `1 - opacity` over the image, so you don't need to make it transparent yourself.

<Warning>
	A background can make text harder to read. Choose semantic colors that stay readable over the image, and use `blur` and a lower `opacity` to keep messages legible.
</Warning>
