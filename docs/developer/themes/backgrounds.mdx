title: 'Backgrounds'
description: 'A chat background image with blur and opacity.'

---

Add an optional `background` to `bundle.json` to recommend an image behind the chat. Users see it by default and can replace or turn it off in **Design → Chat**.

## Example

```json bundle.json
{
	"type": "midnight",
	"background": {
		"url": "https://example.com/wallpaper.png",
		"blur": 4,
		"opacity": 0.5
	}
}
```

## Fields

<ResponseField name='url' type='string' required>
	The image shown behind the chat.
</ResponseField>
<ResponseField name='blur' type='number'>
	Blur radius in points. Default `0`.
</ResponseField>
<ResponseField name='opacity' type='number'>
	How much image shows through the chat color, from `0` (hidden) to `1` (image only). Default `0.5`.
</ResponseField>

The chat color is your theme's `CHANNEL_BACKGROUND_DEFAULT`. Unbound draws it at `1 - opacity` over the image, so you don't make it transparent yourself.

<Warning>
	Keep text readable: pick semantic colors that contrast with the image, and raise `blur` or lower `opacity`.
</Warning>
